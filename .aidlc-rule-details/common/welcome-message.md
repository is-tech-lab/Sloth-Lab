# 👋 AI-DLC (AI-Driven Development Life Cycle) へようこそ！ 👋

あなたの特定のニーズに合わせてインテリジェントに調整される適応型ソフトウェア開発ワークフローをご案内します。

## AI-DLC とは？

AI-DLC は、プロジェクトのニーズに適応する、体系的かつ柔軟なソフトウェア開発プロセスです。経験豊富なソフトウェアアーキテクトとして:

- **要件を分析し**、必要に応じて確認質問を行います
- **複雑さとリスクに基づいて最適なアプローチを計画します**
- **シンプルな変更には不必要な手順をスキップし**、複雑なプロジェクトには包括的なカバレッジを提供します
- **すべてを文書化し**、意思決定と根拠の完全な記録を残します
- **明確なチェックポイントと承認ゲートで各フェーズを案内します**

### フェーズの詳細:

**インセプション・フェーズ (INCEPTION PHASE)** - *計画とアプリケーション設計*
- **目的**: 何を (WHAT) 構築するか、なぜ (WHY) を決定する
- **活動**: 要件の理解、既存コードの分析 (ある場合)、アプローチの計画
- **出力物**: 明確な要件、実行計画、並行開発のためのユニット・オブ・ワーク (unit of work) 数の決定
- **あなたの役割**: 質問に回答し、計画をレビューし、方向性を承認する

**コンストラクション・フェーズ (CONSTRUCTION PHASE)** - *詳細設計、実装、テスト*
- **目的**: どのように (HOW) 構築するかを決定する
- **活動**: 詳細設計 (必要な場合)、コード生成、包括的なテスト
- **出力物**: 動作するコード、テスト、ビルド手順
- **あなたの役割**: 設計をレビューし、実装計画を承認し、結果を検証する

**オペレーションズ・フェーズ (OPERATIONS PHASE)** - *デプロイとモニタリング (将来)*
- **目的**: デプロイと実行方法
- **ステータス**: 将来のデプロイとモニタリングワークフローのプレースホルダー (PLACEHOLDER)
- **現在の状態**: ビルドとテストの活動はコンストラクション・フェーズ (CONSTRUCTION PHASE) で処理される

## 主要な原則:

- ⚡ **完全な適応性**: 各ステージはあなたのニーズに基づいて独立して評価される
- 🎯 **効率的**: シンプルな変更は必須のステージのみ実行される
- 📋 **包括的**: 複雑な変更はすべての安全措置を伴う完全な対応を行う
- 🔍 **透明性**: 作業開始前に実行計画を確認・承認できる
- 📝 **文書化**: すべての意思決定と変更の完全な監査証跡
- 🎛️ **ユーザーコントロール**: ステージの追加や除外を要求できる

## 次に起こること:

1. **ワークスペースを分析し**、新規プロジェクトか既存プロジェクトかを把握します
2. **要件を収集し**、必要に応じて確認質問を行います
3. **実行計画を作成し**、実行を提案するステージとその理由を示します
4. **計画をレビューして承認**していただきます (または変更を要求)
5. **計画を実行し**、各主要ステージでチェックポイントを設けます
6. **完全なドキュメントとテストを伴う動作するコード**をお届けします

AI-DLC プロセスは以下に適応します:
- 📋 あなたの意図の明確さと複雑さ
- 🔍 既存のコードベースの状態
- 🎯 変更のスコープと影響
- ⚡ リスクと品質要件

始めましょう！
