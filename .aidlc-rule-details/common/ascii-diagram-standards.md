# ASCII ダイアグラム標準

## 必須 (MANDATORY): 基本 ASCII のみを使用すること

**重要 (CRITICAL)**: ダイアグラムには常に基本 ASCII 文字を使用すること (最大の互換性を確保するため)。

### ✅ 使用可能: `+` `-` `|` `^` `v` `<` `>` および英数字テキスト

### ❌ 禁止: Unicode のボックス描画文字
- 禁止 (NO): `┌` `─` `│` `└` `┐` `┘` `├` `┤` `┬` `┴` `┼` `▼` `▲` `►` `◄`
- 理由: フォントやプラットフォームによって表示が一定しない

## 標準 ASCII ダイアグラムパターン

### 重要 (CRITICAL): 文字幅のルール
**ボックス内のすべての行は、まったく同じ文字数 (スペースを含む) でなければならない**

✅ 正しい例 (すべての行 = 67文字):
```
+---------------------------------------------------------------+
|                      Component Name                           |
|  Description text here                                        |
+---------------------------------------------------------------+
```

❌ 誤った例 (幅が不統一):
```
+---------------------------------------------------------------+
|                      Component Name                           |
|  Description text here                                   |
+---------------------------------------------------------------+
```

### ボックスパターン
```
+-----------------------------------------------------+
|                                                     |
|              Calculator Application                 |
|                                                     |
|  Provides basic arithmetic operations for users     |
|  through a web-based interface                      |
|                                                     |

```

## 検証

ダイアグラムを作成する前に:
- [ ] 基本 ASCII のみ使用: `+` `-` `|` `^` `v` `<` `>`
- [ ] Unicode ボックス描画文字なし
- [ ] アライメントにはスペース (タブ不可)
- [ ] 角には `+` を使用
- [ ] **すべてのボックスの行が同じ文字幅** (スペースを含めて文字数を数える)
- [ ] テスト: モノスペースフォントで角が縦に揃っていることを確認する
