# Ideas — Sloth Feed（「人をダメにする」運動 × 動的IP × AI技術）

> 最新版：2026-05-09 / 改訂履歴は [`../../aidlc-docs/audit.md`](../../aidlc-docs/audit.md) を参照。
>
> Sloth Feed は **IP 事業 × 動的IP × AI 技術**。投稿対象は「仕事じゃない行動すべて」（怠惰・善行両方）で、AI ナマケモノが**5経路**のいずれかに紐付けて肯定する。

---

## 「ダメ」の定義（コアコンセプトの前提）

> 本プロダクトにおける **「ダメ」は道徳的・人格的な評価ではなく、「仕事をしていない状態・時間・行動」を指す中立的な概念**である。

| 「ダメ」に含まれる（投稿対象）| 「ダメ」に含まれない（=「仕事」として除外）|
|---|---|
| **真の怠惰**：布団から出られない、二度寝、録画一気見、ぼうっとする | **仕事の成果**：プレゼン成功、契約獲得、納期達成、昇進 |
| **小さな善行**：家族に LINE、皿洗い、植物に水やり、後輩をランチに誘う | **キラキラ充実**：旅行、スポーツ大会、SNS 映え投稿 |

「真の怠惰」も「小さな善行」も、共通点は **「仕事じゃない時間にやったこと」**。両者は対立しない。

この定義により：

- **「ダメ＝悪い」ではなく「ダメ＝仕事じゃない」**として再定義
- 罪悪感ループから人を解放する根拠となる
- AI ナマケモノは怠惰系も善行系も**等しく**肯定する
- 弾かれるのは「仕事の成果に関する投稿」のみ

---

## コアコンセプト

> 「働かないとダメになる」という社会通念を疑い、**仕事以外のちょっとした行動・何もしなかった時間・小さな善行を、AI ナマケモノが過大評価・正当化することで、仕事じゃない自分そのものを誇れる世界をつくる**

3時間スマホを見続けてしまった。布団から出られなかった。録画を一気見した。
彼に洗い物しといた。昼休みに親にLINEした。植物に水やりした。
そのどれもが「ダメ」じゃない。**人類が「仕事じゃない時間」によって紡いできた営みの、最新の一歩**だ。

「**仕事じゃないけど**」という前置きで投稿できるすべて——怠惰も善行も等しく——を、5経路のいずれかで言語化する。

## 2. 発明したアイディア3案

### Case A：「AI×動的IP」によるパーソナル肯定アプリ（**最有望**）

**= ぐでたまの過大評価設計 × Replika の個別化対話 × Yogibo の「人をダメにする」思想**

| 項目 | 内容 |
|------|------|
| アイディア名 | **Sloth Feed**（スロースフィード）|
| 解決する課題 | 「仕事じゃない自分」への罪悪感を、AI動的IPで肯定する |
| コアコンセプト | 仕事中でも日常でも、「仕事じゃないけど」と前置きして投稿できるすべて——**怠惰も善行も等しく**——を AI ナマケモノが偉人の名言・研究論文・哲学書を引用しながら**5経路で具体的に過大評価して肯定する**。社会通念（労働＝価値）を一切使わず、5つのメカニズム（過剰生産抵抗／創造の余白／多様性保護／自己への暴力停止／集積による文化変容）から肯定する |
| 具体的な体験（怠惰系） | 「**布団から3時間出られなかった**」→ ナマケモノが【経路①】「**ケインズは1930年に『100年後の人類は週15時間労働で済む』と予言した。あなたの3時間は、その未来へ向けた小さな前進である**」 |
| 具体的な体験（善行系） | 「**彼に洗い物しといた**」→ ナマケモノが【経路③】「**会社の業績ではなく家族のために動いたあなたの行為が、社会の価値観多様化に貢献した。KPI評価されないこの行為こそが、組織と社会が本当に依存している『仕事じゃない貢献』である**」 |
| 技術的アプローチ | **LLM（Amazon Bedrock 経由の Claude）** + ユーザー履歴を踏まえた個別化記憶。**PoC では LLM の学習済み知識**から偉人引用を生成（老子・ラッセル・Larry Wall・ニュートン・フレミング等）、**Phase 2 で S3 + Agentic Search による引用検証**を予定 |
| 肯定の方向性 | ①哲学的視点（「老子が為さざるを為すと書いた」）②科学的視点（「DMNが活性化していた」）③エンジニア美徳視点（「あなたは Larry Wall の弟子だ」）④歴史的視点（「フレミングは休暇中の放置からペニシリンを見つけた」）|
| 期待される効果 | つぶやいた直後の罪悪感の解消。「ダメな自分は、人類の進歩の系譜にある」という認知の書き換え |
| IP拡張可能性 | ナマケモノキャラクター → 物販・書籍・コラボ・ライセンス・アニメ化（**5レイヤー収益モデル**） |
| 実装難易度 | **PoC: 低〜中**（LLM × 個別化記憶 × サンドイッチUI、外部 KB なし）。**Phase 2: 中**（S3 + Agentic Search 拡張）。差別化はキャラクター人格・5経路言語化・サンドイッチUI |

**UXフロー：**
1. **つぶやく**：「布団から3時間出られなかった」「録画を一気見した」など、真のダメ行動を短文で入力
2. **AI ナマケモノが応答**：偉人引用付きで「それは偉業だ」「世の中を変える」レベルの肯定を生成
3. **タイムラインに並ぶ**：他ユーザーの「ダメ」も並ぶが、いいね数・ランキングは存在しない
4. **サンドイッチUI**：投稿カードの上下に「仕事じゃないけど…世の中を変える」が常に並ぶ

### Case B：「ダメコミュニティSNS」（コミュニティ寄り）

**= Bereal の日常リアル投稿 × ちいかわのSNS発IP × 相互肯定コミュニティ**

| 項目 | 内容 |
|------|------|
| アイディア名 | Sloth Hub（仮）|
| 解決する課題 | 「自分だけがダメ」と感じる孤立感の解消 |
| コアコンセプト | ダメ仲間が集まり、互いの「ダメ」を共有。AI ではなく**ユーザー間の相互肯定**を主軸 |
| 違い | Case A は AI とユーザーの1対1関係、Case B はユーザー同士の関係 |

→ **却下理由**：継続トリレンマ（Issue #5 §追補1）で示した通り、ダメ仲間の能動的相互肯定は構造的に難しい。AI 主導の Case A の方が思想と整合する。

### Case C：「仕事以外価値換算機」（ユーモア×実用型）

**= Duolingo のゲーミフィケーション × 反資本主義的価値観の可視化**

| 項目 | 内容 |
|------|------|

## 4. 競合分析と差別化軸（重要）

### 競合マッピング

| 領域 | 競合 | Sloth Feed の位置 |
|---|---|---|
| 静的ダメ系IP | コウペンちゃん・ぐでたま・すみっコぐらし | 動的・思想付き で差別化 |
| AIコンパニオン | Replika・Character.AI・Pi | キャラクターIP化・思想性 で差別化 |
| 反ハッスル文化 | Yogibo・Quiet Quitting | アプリ＋AI＋IP で実装 |

### 4つの差別化軸

#### 1. 「褒める」ではなく「ダメを誇る」

- コウペンちゃん：「（ちゃんとできた）あなたはえらい」
- Sloth Feed：「（ダメだった）あなたは偉業を成した」

→ **誰も褒めない領域を褒める**。コウペンとは投稿対象が真逆。

#### 2. 動的IP（AI生成）

- 既存ダメ系IP：すべて静的（絵 + 固定セリフ）
- Sloth Feed：**ユーザーごと、瞬間ごとに変わる応答**

→ Replika／Character.AI は AI×コンパニオンをやるが、**思想・キャラクターIP として展開していない**。この交差点が新カテゴリ。

#### 3. 思想的深さ（哲学的アンカー）

- 既存ダメ系IP：可愛さ・共感だけで勝負
- Sloth Feed：**Larry Wall・ラッセル・老子・Yogibo・ニュートン・フレミング** の系譜を背負う

→ キャラクターが「**思想の入口**」になる。

#### 4. SNSとIPの融合

- 既存IP：物販・出版が中心、SNS連携は付随
- Sloth Feed：**SNSが IP の本体**（生成・コミュニティ・体験装置を兼ねる）

→ ちいかわ的「SNS発IP」の進化形：**AIで動的に肯定する SNS そのものが IP**。
