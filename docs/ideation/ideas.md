# Ideas — だらけ正当化プロダクト

## コアコンセプト

> 「働かないとダメになる」という社会通念を疑い、**仕事以外のちょっとした行動を過大評価・正当化することで、だらけている自分を肯定する世界をつくる**

仕事中に彼女のためにふと気づいて家事をやった。  
それはサボりではない。**人間として最も重要なことをやった**のだ。

## 2. 発明したアイディア3案

### Case A：「偉業つぶやき＆AI過剰称賛アプリ」（メインコンセプト）
**= Duolingo の「過剰称賛設計」× Adulting Meme の「日常偉業化」× LLM**

| 項目 | 内容 |
|------|------|
| アイディア名 | **Sloth Log（スロースログ）** |
| 解決する課題 | 「仕事以外のことをやった自分」を正当化し、罪悪感を消す |
| コアコンセプト | 仕事中でも日常でも、「ちょっとしたこと」をつぶやくと、AIが**圧倒的に過大評価して称賛してくれる**アプリ。社会通念（働くこと＝価値）を無視した視点から、人間的行動を偉業として再定義する |
| 具体的な体験 | 「仕事中に気づいて、彼女のために洗い物しといた」→ AIが「あなたは今日、愛する人の生活を守った。どんな会議より価値のある15分だった。人類が失いかけている"気づく力"をあなたは持っている。」と返す |
| 技術的アプローチ | LLMによる「過大評価特化プロンプト」。入力した行動を"社会的価値の再定義"フレームで称賛。仕事の生産性軸を一切使わない称賛ロジック |
| 称賛の方向性 | ①人間関係視点（「あなたの気づきが誰かの日常を支えた」）②反社会通念視点（「会社の仕事より大切なことをやった」）③哲学的視点（「資本主義が見落としてきた価値を、あなたは今日実践した」） |
| 期待される効果 | つぶやいた直後の罪悪感の解消。「仕事以外のことをやった自分は正しい」という認知の書き換え |
| 実装難易度 | 低〜中（LLM API統合＋シンプルな投稿UI。差別化はプロンプト設計と称賛トーンの精度） |

**UXフロー：**
1. **つぶやく**：「仕事中に〇〇した」「今日△△しといた」を短文で入力
2. **過剰称賛が来る**：AIが「それは偉業だ」「社会が見落としてきた価値をあなたが示した」レベルの返答を生成
3. **蓄積される**：「今日の偉業リスト」として記録。仕事の成果ではなく、人間的行動の記録として積み上がる
4. **比較なし**：他人の「頑張り」と並べる機能はゼロ。自分の偉業だけが残る

### Case B：「偉業シェアコミュニティ」（SNS型）
**= Bereal の「日常リアル投稿」× Adulting Meme の「偉業化ユーモア」× 相互称賛コミュニティ**

| 項目 | 内容 |
|------|------|
| アイディア名 | **Sloth Feed（スロースフィード）** |
| 解決する課題 | Instagramの「充実した人との比較」による自己評価低下を逆転させる |
| コアコンセプト | 「仕事以外のちょっとした行動」だけを投稿できるSNS。投稿内容は「仕事の成果」「旅行」「充実した休日」禁止。「気づいたら家の電球換えてた」「昼休みに親にLINEした」レベルのことだけ投稿できる |
| リアクション設計 | 「すごい」「天才」「人類の希望」の3種類のスタンプのみ。「いいね」の数は非表示。競争・比較が生まれない設計 |
| 技術的アプローチ | 投稿フィルタリング（「仕事の成果」「旅行」などのキーワードをAIで検出し投稿制限）。匿名可 |
| 期待される効果 | 「私のこんな小さなことで、みんな"天才"って言ってくれる」という体験。Instagramとは真逆の自己評価向上 |
| 実装難易度 | 中（コミュニティ設計・投稿フィルタリング・コールドスタート問題が課題） |

---

### Case C：「仕事以外価値換算機」（ユーモア×実用型）
**= Duolingo の「ゲーミフィケーション」× 反資本主義的価値観の可視化**

| 項目 | 内容 |
|------|------|
| アイディア名 | **Real ROI（リアルROI）** |
| 解決する課題 | 「仕事をしていない＝価値を生んでいない」という思い込みを数値で壊す |
| コアコンセプト | 仕事以外のちょっとした行動を入力すると、AIが**その行動の「本当の社会的価値」を円換算・時間換算で出してくれる**。「彼女に洗い物しといた」→「関係継続コスト削減：月約43,000円相当、精神的安定への寄与：プライスレス」 |
| 技術的アプローチ | LLMによる価値換算ロジック生成。感情的価値・関係的価値・健康的価値など「仕事の給与」では計れない軸で計算 |
| ユーモア設計 | 真面目に計算するのではなく、「ふざけた真剣さ」で数値化。笑えるけど「確かにそうだな」と思えるトーン |
| 期待される効果 | 「仕事の生産性」以外の価値軸の存在を実感。ペルソナBの「本気出せばできる＝自分は優秀」という歪んだ自己評価を、別軸の価値観で補完 |
| 実装難易度 | 低（LLM API統合のみ。UIはシンプルな入力→出力で完結） |

## 3. 最有望案の選択

### 選択：**Case A — Sloth Log（スロースログ）**

| 評価軸 | Case A（Sloth Log） | Case B（Sloth Feed） | Case C（Real ROI） |
|--------|-------------------|--------------------|--------------------|
| 罪悪感への即効性 | 高（つぶやいた直後に解消） | 中（他者反応待ちが発生） | 中（笑えるが感情への深度が浅い） |
| 継続しやすさ | 高（毎日の自然なつぶやきに乗れる） | 中（投稿する気力が必要） | 低（毎日使うより一発ネタ寄り） |
| ペルソナへの刺さり方 | 高（Aの罪悪感・Bの自己過大評価どちらにも効く） | 中（Aに効くが、Bには薄い） | 中（Bのユーモアに刺さるがAには薄い） |
| 実装難易度 | 低〜中 | 中〜高 | 低 |
| 独自性 | 高（「仕事以外を過大評価する」特化プロダクトは存在しない） | 中（逆張りSNSは競合あり） | 中（ユーモアアプリは競合あり） |
| **総合** | **🏆 最有望** | 次点 | 次点 |

**選択理由：**
- 「仕事中に彼女のために家事をやった」という具体的なシーンに、**その場で・即座に**応えられる唯一の設計
- 「働くこと＝価値」という社会通念を、説教なくユーモアとAIの過剰称賛で自然に書き換えられる
- ペルソナA（罪悪感型）にもペルソナB（優越感型）にも刺さる：AはAIに認めてもらえる体験を求め、Bは「俺の行動の真の価値をわかってるのはこのAIだけだ」と感じる
- LLMの「文脈を踏まえた称賛文生成」がそのまま差別化になるため、技術的参入障壁を作りやすい
