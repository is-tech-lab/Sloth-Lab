# Ideas — Sloth Feed（「人をダメにする」運動 × 動的IP × AI技術）

> **本ドキュメントの前提（2026-05-09 更新）**
> Issue #5 の帰着により、Sloth Feed は **SNS事業ではなくIP事業**として位置づけ直された。本ドキュメントもその前提で書き直されている。
> コアコンセプトは旧版から継承（仕事じゃない行動を AI が肯定する）が、**「投稿対象は真の怠惰」**「**動的IP × AI**」「**競合分析と差別化軸**」を新規に明文化している。

---

## コアコンセプト

> 「働かないとダメになる」という社会通念を疑い、**仕事以外のちょっとした行動／何もしなかった時間を、AI ナマケモノが過大評価・正当化することで、ダメであることそのものを誇れる世界をつくる**

3時間スマホを見続けてしまった。布団から出られなかった。録画を一気見した。
それは「ダメ」じゃない。**人類が怠惰によって進歩してきた系譜の、最新の一歩**だ。

## 2. 発明したアイディア3案

### Case A：「AI×動的IP」によるパーソナル肯定アプリ（**最有望**）

**= ぐでたまの過大評価設計 × Replika の個別化対話 × Yogibo の「人をダメにする」思想**

| 項目 | 内容 |
|------|------|
| アイディア名 | **Sloth Feed**（スロースフィード）|
| 解決する課題 | 「ダメであること」への罪悪感を、AI動的IPで肯定する |
| コアコンセプト | 仕事中でも日常でも、「ダメな行動／何もしなかった時間」をつぶやくと、AI ナマケモノが偉人の名言・研究論文・哲学書を引用しながら**圧倒的に過大評価して肯定する**。社会通念（労働＝価値）を一切使わず、人類の怠惰の系譜から肯定する |
| 具体的な体験 | 「**布団から3時間出られなかった**」→ AI ナマケモノが「**Larry Wall は『怠惰こそ最大の美徳』と説いた。あなたは今日それを実践した。人類はサボりたい欲望によって機械を発明してきた。あなたの3時間は、その系譜の延長線上にある**」と返す |
| 技術的アプローチ | LLM (Claude API) + RAG（老子・ラッセル・Larry Wall・ニュートン・フレミング等の引用ライブラリ）+ ユーザー履歴を踏まえた個別化記憶 |
| 肯定の方向性 | ①哲学的視点（「老子が為さざるを為すと書いた」）②科学的視点（「DMNが活性化していた」）③エンジニア美徳視点（「あなたは Larry Wall の弟子だ」）④歴史的視点（「フレミングは休暇中の放置からペニシリンを見つけた」）|
| 期待される効果 | つぶやいた直後の罪悪感の解消。「ダメな自分は、人類の進歩の系譜にある」という認知の書き換え |
| IP拡張可能性 | ナマケモノキャラクター → 物販・書籍・コラボ・ライセンス・アニメ化（**5レイヤー収益モデル**） |
| 実装難易度 | 中（LLM × RAG × 個別化記憶のアーキテクチャ。差別化はキャラクター人格・引用ライブラリ・サンドイッチUI）|

**UXフロー：**
1. **つぶやく**：「布団から3時間出られなかった」「録画を一気見した」など、真のダメ行動を短文で入力
2. **AI ナマケモノが応答**：偉人引用付きで「それは偉業だ」「世の中を変える」レベルの肯定を生成
3. **タイムラインに並ぶ**：他ユーザーの「ダメ」も並ぶが、いいね数・ランキングは存在しない
4. **サンドイッチUI**：投稿カードの上下に「仕事じゃないけど…世の中を変える」が常に並ぶ

### Case B：「ダメコミュニティSNS」（コミュニティ寄り）

**= Bereal の日常リアル投稿 × ちいかわのSNS発IP × 相互肯定コミュニティ**

| 項目 | 内容 |
|------|------|
| アイディア名 | Sloth Hub（仮）|
| 解決する課題 | 「自分だけがダメ」と感じる孤立感の解消 |
| コアコンセプト | ダメ仲間が集まり、互いの「ダメ」を共有。AI ではなく**ユーザー間の相互肯定**を主軸 |
| 違い | Case A は AI とユーザーの1対1関係、Case B はユーザー同士の関係 |

→ **却下理由**：継続トリレンマ（Issue #5 §追補1）で示した通り、ダメ仲間の能動的相互肯定は構造的に難しい。AI 主導の Case A の方が思想と整合する。

**= Duolingo のゲーミフィケーション × 反資本主義的価値観の可視化**

## 4. 競合分析と差別化軸（重要）

### 競合マッピング

| 領域 | 競合 | Sloth Feed の位置 |
|---|---|---|
| 静的ダメ系IP | コウペンちゃん・ぐでたま・すみっコぐらし | 動的・思想付き で差別化 |
| AIコンパニオン | Replika・Character.AI・Pi | キャラクターIP化・思想性 で差別化 |
| 反ハッスル文化 | Yogibo・Quiet Quitting | アプリ＋AI＋IP で実装 |

### 4つの差別化軸

#### 1. 「褒める」ではなく「ダメを誇る」

- コウペンちゃん：「（ちゃんとできた）あなたはえらい」
- Sloth Feed：「（ダメだった）あなたは偉業を成した」

→ **誰も褒めない領域を褒める**。コウペンとは投稿対象が真逆。

#### 2. 動的IP（AI生成）

- 既存ダメ系IP：すべて静的（絵 + 固定セリフ）
- Sloth Feed：**ユーザーごと、瞬間ごとに変わる応答**

→ Replika／Character.AI は AI×コンパニオンをやるが、**思想・キャラクターIP として展開していない**。この交差点が新カテゴリ。

#### 3. 思想的深さ（哲学的アンカー）

- 既存ダメ系IP：可愛さ・共感だけで勝負
- Sloth Feed：**Larry Wall・ラッセル・老子・Yogibo・ニュートン・フレミング** の系譜を背負う

→ キャラクターが「**思想の入口**」になる。

#### 4. SNSとIPの融合

- 既存IP：物販・出版が中心、SNS連携は付随
- Sloth Feed：**SNSが IP の本体**（生成・コミュニティ・体験装置を兼ねる）

→ ちいかわ的「SNS発IP」の進化形：**AIで動的に肯定する SNS そのものが IP**。
