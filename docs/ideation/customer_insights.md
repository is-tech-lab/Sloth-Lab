# 顧客理解レポート

> 対象プロダクト：共鳴する怠惰（仮称）  
> 課題：「サボっていい気がしない」「ただ存在するだけで許されたい」という、日本の働く世代が抱える慢性的な罪悪感と自己肯定の欠乏

---

## 1. ペルソナ

### ペルソナA：田中 麻衣（28歳）

| 項目 | 内容 |
|------|------|
| 年齢 | 28歳 |
| 家族構成 | 一人暮らし |
| 職業 | IT企業・マーケター（在宅勤務メイン） |
| 趣味 | Netflix、Twitterのタイムライン眺め、コンビニスイーツ開拓 |

**1日のスケジュール（休日）**

| 時間帯 | 行動 |
|--------|------|
| 10:00 | 起床。スマホでSNSチェック。友人の「朝活ランニング完走！」投稿を見て小さく萎える |
| 11:00 | 「何か生産的なことしなきゃ」と思いながらもベッドから出られない |
| 13:00 | ようやく起き上がり、Netflixを流しながらお菓子を食べる |
| 15:00 | 「あ、今日も何もしてない」と漠然とした罪悪感 |
| 17:00 | 「もう夕方だし今日はいいや」と開き直ろうとするが、完全には開き直れない |
| 22:00 | 「明日こそは…」とSNSを見ながら就寝 |

**課題に直面する心理的必然性：**  
在宅勤務により仕事とプライベートの境界が消え、「常にやるべきことがある感」が慢性化。SNSでは生産的な他者が可視化され続ける一方、自分の怠惰は完全に孤独な罪悪感として処理される。「サボっていいのは自分だけでは」という孤立感が根底にある。

## まとめ・インサイト

ターゲットユーザーが本当に欲しいのは「怠ける手段」ではなく、**「怠けることへの許可証」**。  
その許可を最も強く与えられるのは、権威ある人間の言葉でも自己啓発でもなく、**「今この瞬間、自分の近くにも同じようにだらけている誰かがいる」という事実の可視化**である。

SNSは「充実した他者」を増幅させるが、本サービスは「怠惰な他者」を可視化する逆SNS。  
これが差別化の核心。
