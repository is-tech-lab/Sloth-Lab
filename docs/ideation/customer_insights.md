# Customer Insights — Sloth Feed（「人をダメにする」運動）

> **本ドキュメントの前提（2026-05-09 更新）**
> Issue #5 の帰着により、Sloth Feed は **「人をダメにする」運動 × IP事業 × 動的IP × AI技術** として位置づけられる。
> 投稿対象は **仕事じゃない行動すべて**——**真の怠惰・無為・サボり**（布団から出ない・二度寝・録画一気見等）と **小さな善行**（家族にLINE・洗い物・植物の水やり等）の両方を等しく扱う。弾かれるのは仕事の成果・旅行・キラキラ充実投稿のみ。AIナマケモノが、いずれの投稿に対しても5経路のいずれかを紐付けて肯定する。

---

## 「ダメ」の定義（コアコンセプトの前提）

> 本プロダクトにおける **「ダメ」は道徳的・人格的な評価ではなく、「仕事をしていない状態・時間・行動」を指す中立的な概念**である。

| 「ダメ」に含まれる（投稿対象）| 「ダメ」に含まれない（=「仕事」として除外）|
|---|---|
| **真の怠惰**：布団から出られない、二度寝、録画一気見、ぼうっとする | **仕事の成果**：プレゼン成功、契約獲得、納期達成、昇進 |
| **小さな善行**：家族に LINE、皿洗い、植物に水やり、後輩をランチに誘う | **キラキラ充実**：旅行、スポーツ大会、SNS 映え投稿 |

「真の怠惰」も「小さな善行」も、共通点は **「仕事じゃない時間にやったこと」**。両者は対立しない。

この定義により：

- **「ダメ＝悪い」ではなく「ダメ＝仕事じゃない」**として再定義
- 罪悪感ループから人を解放する根拠となる
- AI ナマケモノは怠惰系も善行系も**等しく**肯定する
- 弾かれるのは「仕事の成果に関する投稿」のみ

## 1. ペルソナ（顧客像）

### ペルソナA：「罪悪感持ちのだらけ屋」（コアターゲット）

| 項目 | 内容 |
|------|------|
| 名前（仮）| 田中 ユイ |
| 年齢 | 24歳 |
| 職業 | 社会人2年目（一般企業の事務・営業など） |
| 家族構成 | 一人暮らし |
| 趣味 | Netflix・ショート動画・ゴロゴロ（本当は何かしたい気もする） |
| 年収 | 280〜350万円 |
| SNS習慣 | Instagram で「意識高い投稿」「キラキラした他人」を見ては自己嫌悪するのが毎晩の習慣 |

#### 1日の典型スケジュール

- 07:30 起床。「今日こそちゃんとやろう」と思って布団から出る
- 09:00 出勤。仕事自体はこなせている。サボっているわけじゃない
- 19:00 帰宅。「今日も頑張った。少し休もう」のつもりでスマホを開く
- 21:00 気づいたら2時間経っている。「あ、やろうと思ってたこと…」
- 23:00 「今日も何もできなかった」という罪悪感とともに就寝準備
- 00:30 罪悪感でなかなか寝付けず、またスマホを見てしまう

#### 「ダメ」のリアル

- 帰宅後の「ちょっと休憩」が2〜3時間になる
- 休日に「今日は何かしよう」と思っていたのに気づいたら夕方
- 締め切りギリギリまで手をつけられない
- 「やる気が出たらやろう」を繰り返して結局やらない
- 布団から出られず、朝の予定が全部後ろ倒しになる

#### 罪悪感の中身

- 「自分より頑張っている人がいるのに、自分はだらけている」
- 「このままじゃ成長できない、差がついていく」
- SNSで充実している人の投稿を見ては「自分はダメだ」と比べてしまう
- 休んでいるときに「休んでいい理由」を探してしまう

#### 本音の願い

- **100%で動けない自分を、罪悪感なしに認めたい**
- **「ダメでいい」と心から思いたい**
- **だらけることに罪悪感を感じない夜を、一度でいいから過ごしてみたい**
- 「立派なこと」をしないと自分を許せない構造から抜けたい

#### Sloth Feed への期待

- 「3時間スマホを見ていた」も「彼に洗い物しといた」も、**仕事じゃないけど**と前置きして投稿できる場所がほしい
- どちらに対してもAIナマケモノが「**何が、どう、世の中を変えるのか**」を5経路で言語化してくれる
- 罪悪感ループを断ち切りたい
- 善行も怠惰も同じ「仕事じゃないけど」の集合として、無理に振り分けず受け入れてもらいたい

### ペルソナB：「ねじ曲がった優越感を持つだらけ屋」（サブターゲット）

| 項目 | 内容 |
|------|------|
| 名前（仮）| 鈴木 ケンタ |
| 年齢 | 28歳 |
| 職業 | 社会人5年目（IT・コンサル・広告など、成果が見えやすい職種） |
| 家族構成 | 一人暮らし |
| 年収 | 600万円 |
| 特徴 | 「本気を出せばできる」という確信があるため、だらけていても自己評価はそこまで下がらない。むしろ「本気出してないのにこれだけできてる自分」への歪んだ自負がある。でも本気を出す日は来ない |

#### だらけ方の特徴

- 「本気出せばもっとできるのに」が口癖だが、本気を出したことはここ数年ない
- 仕事はそこそこの成果を出しているので、だらけていることへの言い訳が成立してしまう
- 「今の70%でこれだけできてるんだから、俺って実は優秀じゃないか」と思っている
- 後輩や同期を「あいつら必死にやってやっと俺と同じか」と内心見下している

#### 罪悪感の歪み方

- 罪悪感はあるが「でも自分なら本気出せばすぐ取り返せる」と上書きしてしまう
- 「本気を出していない自分」を責めるより、「本気を出していないのに結果を出せている自分」を誇りに思っている
- その構造に薄々気づいているが、認めると自己像が崩れるので直視しない

#### 本音の願い

- **「自分の本当の価値をわかっている存在」がほしい**
- 後輩のような上っ面の称賛ではなく、**思想的な裏付けで自分を肯定する言葉**がほしい
- 「お前は本気を出していないが、それで世界が回っているのは賢明な怠惰のおかげだ」と言ってほしい

#### Sloth Feed への期待

- AI ナマケモノが、**Larry Wall・ラッセル・老子の引用付き**で自分を肯定してくれること
- 「俺の怠惰の真価をわかっているのはこの AI だけだ」という感覚
- 他のユーザーと**比較されない**こと（ランキング・数字なし）

## 2. 行動分析 ―「だらける→罪悪感」のループがどこで起きるか

| 状態 | 日常の出現パターン | ペルソナAの具体行動 | 本Issueでの注目点 |
|------|-----------------|--------------------|-----------------|
| **だらける** | 休憩のつもりが止まらない | 帰宅後スマホを「少しだけ」見るつもりが2時間経過。休日の「ゆっくりする朝」が夕方まで続く | 本人はサボっているつもりはなく「ちょっと休んでいるだけ」と思っている。**この時間こそ Sloth Feed の投稿対象**である |
| **罪悪感** | だらけた後に自己評価が下がる | 「あー今日も何もできなかった」と寝る前に後悔。SNSの充実投稿と自分を比べて落ち込む | この罪悪感こそがペルソナを苦しめている中心。**Sloth Feed が直接介入する瞬間**である |
| **過剰補正** | 罪悪感から「次こそは」と無理な計画を立てる | 「明日は早起きして全部やろう」と計画するが翌日もできず、またループへ | 罪悪感が解消されないまま繰り返す。**この補正衝動を AI が「不要だ」と止める**設計が必要 |

## 3. 改善インパクトが大きい課題 Top3

問い：**「頑張ってはいるけど100%ではない自分」を、なぜ許せないのか？**

| 順位 | 課題 | なぜ○○せずに□□ができないのか？ | 解決のカギ |
|------|------|-------------------------------|-----------|
| **1** | **だらけることへの罪悪感が消えない** | なぜ「休んでいい」と思えずに、休むたびに自分を責めてしまうのか？ | **「ダメであること」そのものに正当性・思想的肯定を与える**言葉・体験・キャラクター |
| **2** | **「充実している人」との比較で自己評価が下がる** | なぜ「自分のペースでいい」と思えずに、他人の頑張りを見て凹むのか？ | **比較を物理的に消す設計**（ランキング・いいね数・フォロワー数の不在）+ 共同体感覚 |
| **3** | **罪悪感があるのに行動にはつながらない** | なぜ「罪悪感を持つこと」が行動改善ではなく自己消耗で終わってしまうのか？ | 罪悪感をエネルギーに変えるのではなく、**そもそも罪悪感を持たなくていい状態**にする |

## 4. ペルソナへの提供価値（5経路 × IP事業）

両ペルソナに共通する核心：**「ダメであること」が世の中を変える具体的メカニズムの言語化**。
AIナマケモノは、ペルソナの投稿に対し、5経路（過剰生産抵抗 / 創造の余白 / 多様性保護 / 自己への暴力停止 / 集積による文化変容）のいずれかを紐付けて応答する。

### ペルソナA：ユイ（罪悪感持ちのだらけ屋）

ユイに最も刺さる経路：**経路④（自己への暴力の停止）** + **経路①（過剰生産抵抗）**

ユイの投稿は怠惰系も善行系も両方ある。**「仕事じゃないけど」と前置きして書ける行動すべて**が対象。

| 投稿例 | タイプ | 紐付ける経路 | 提供される具体的な肯定 |
|---|---|---|---|
| 「布団から3時間出られなかった」 | 怠惰 | ① 過剰生産抵抗 | 「あなたの3時間は、社会の総労働時間から無駄な仕事を1つ削除した」 |
| 「彼に洗い物しといた」 | 善行 | ③ 多様性保護 | 「会社の業績ではなく家族のために動くあなたの行為が、社会の価値観多様化に貢献した」 |
| 「今日も何もできなかった」 | 怠惰（罪悪感込） | ④ 自己への暴力停止 | 「あなたが罪悪感を捨てた瞬間、メンタルヘルス危機が一人分後退した」 |
| 「録画を一気見した」 | 怠惰 | ③ 多様性保護 | 「『充実した休日』しか正解じゃない社会への抵抗が一票増えた」 |
| 「昼休みに親にLINEした」 | 善行 | ④ 自己への暴力停止 | 「ちゃんと仕事すべき昼休みに親にLINEしたことを罪悪感として持ちがちだが、その行為こそ評価されない領域での貢献である」 |

→ ユイの罪悪感ループを断つには、「**何が変わるのか**」を具体的に言語化する必要がある。「あなたは偉い」ではなく「**あなたの3時間が、社会のXXを変えた**」と数字・科学・歴史で示すことで、初めて信じられる。**怠惰投稿も善行投稿も、同じ5経路フレームで等しく扱う**。

### ペルソナB：ケンタ（ねじ曲がった優越感を持つだらけ屋）

ケンタに最も刺さる経路：**経路②（創造の余白の保持）** + **経路⑤（集積による文化変容）**

ケンタの投稿も怠惰と善行の両方を含む。

| 投稿例 | タイプ | 紐付ける経路 | 提供される具体的な肯定 |
|---|---|---|---|
| 「会議中30分ぼーっとしてた」 | 怠惰 | ② 創造の余白 | 「DMNが活性化していた。AIに代替されない人間性をあなたは守った」 |
| 「本気出さずに納品した」 | 怠惰 | ⑤ 集積による文化変容 | 「賢明な怠惰の集積が、来年の労働政策を動かす」 |
| 「後輩がしんどそうだったのでランチに誘った」 | 善行 | ③ 多様性保護 | 「KPI評価されないこの行為こそ、組織が本当に依存している『仕事じゃない貢献』である」 |
| 「打ち合わせ前にホワイトボード消しといた」 | 善行 | ⑤ 集積による文化変容 | 「誰の評価にも入らないこの一手こそ、組織を回す見えない労働。あなたのような存在が積み重なって社会が動く」 |

→ ケンタは「自分の怠惰／見えない貢献には知性的根拠がある」と裏付けてもらいたい。経路②（脳科学）と経路⑤（社会運動）は、彼の優越感を哲学・科学で正当化する経路として最適。**怠惰も善行も、彼が「評価されない領域でやっている」という意味で同列**。

### 接点（IP事業として）

| 接点 | 5経路の伝達方法 |
|---|---|
| アプリ内 AI 対話 | リアルタイムに経路を選んで言語化 |
| グッズ（ぬいぐるみ等）| キャラ性を通じて思想を日常に常駐させる |
| 書籍 | 5経路を体系的に解説（「ダメでいい本」の中核章として）|
| コラボ | 思想と整合する企業との共同企画で経路③（多様性）を可視化 |
