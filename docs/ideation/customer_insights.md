# Customer Insights — Refactor the World

## 1. ペルソナ（顧客像）

### ペルソナA：「アーキテクト気質の不満族」（コアターゲット）

| 項目 | 内容 |
|------|------|
| 年齢 | 26歳 |
| 職業 | スタートアップのプロダクトマネージャー（または大手IT企業の若手エンジニア） |
| 家族構成 | 独身、都市部の1Kに一人暮らし |
| 趣味 | デザイン批評、Redditでの議論、都市散策しながらの問題発見 |
| 年収 | 450〜600万円 |
| SNS習慣 | X（Twitter）、Instagram、note に週10〜20件投稿 |

**1日の簡単なスケジュール**
- 08:00 起床、SNSチェックしながら「なんでこんなクソみたいなことしてるんだろうな〜」とぼやき
- 09:30 通勤、通勤路や電車の乗車中に携帯をいじって脳死でゲームやらSNSをするのが日課
- 12:00 昼食、飲食店のメニューUIや盛り付けに「俺ならこうする」と不満や改善案を想像(その時ふと思うだけで実際の行動は何もしない)
- 19:00 退勤、街の非効率に気づきながらも「別に俺が考えることじゃないしな〜」と放置
- 22:00 X（Twitter）で世界批評を垂れ流す、「いいね」が来ると満足感
- 25:00 就寝、すぐに寝付けずSNSを徘徊するかyoutubeを見るか、ゲームをして寝落ちる

**この課題に直面する心理的・状況的必然性**
- 「思うことはある、でも実行する気はない」という不満や文句を抱え込むだけ。
- 「やろうと思ったらできる」と思い込むが実際何も行動しない。
- 専門家（建築家・デザイナー）への「あいつらセンスない」という優越感と、自分が動けない劣等感の共存
- 「俺のアイデアを誰かが実現したら最高なのに」という他力本願な理想

## 2. 行動分析 ——「怠惰・短期・傲慢」が日常のどこに出るか

3つの弱さがペルソナAの1日の中でどう顕在化するかを整理する。

| 弱さ | 日常の出現パターン | ペルソナAの具体的な行動 | 企業にとっての意味 |
|------|-----------------|----------------------|-----------------|
| **怠惰** | 問題を認識しても行動に移さない。「俺がやることじゃない」で完結する | 通勤中に導線の悪さに気づくが誰にも言わない。退勤時に街の非効率を「別に俺が考えることじゃないしな〜」と放置。改善案は脳内にあるが外に出てこない | 問題を認識している人間が行動しないため、そのインサイトが企業の耳に届かない |
| **短期** | 「今この瞬間の刺激」しか受け付けない。待てない、完了できない | 25時まで起きているのにSNS・YouTube・ゲームを渡り歩き続ける。1コンテンツへの集中は数十秒。SNS投稿後、いいねが来なければ数分で次の話題へ移動 | 問題に遭遇した「その瞬間」のエンゲージメントピークを誰も捕捉できていない |
| **傲慢** | 「自分のアイデアは優れている」という確信を持つが、発信しても届かないと知っている | 「飲食店の盛り付け、俺ならこうする」と改善案を脳内で組み立てる。X（Twitter）で世界批評を垂れ流すが「どうせ変わらない」という諦めと共存 | 自己評価の高い人々が持つ改善アイデアが、企業の意思決定に届くルートがない |

## 3. 企業がまだ活かしきれていない課題 Top3

問い：**怠惰・短期・傲慢から生まれる事象を、企業が有利に使えていない原因は何か？**

| 順位 | 弱さ | 生まれる事象 | 活かしきれていない原因 | 企業が有利に使うカギ |
|------|------|------------|---------------------|-------------------|
| **1** | **怠惰** | 大多数の人が問題に気づいているが行動しないため、潜在的な不満・改善アイデアが永遠に表に出ない | 既存の市場調査（アンケート・レビュー・インタビュー）はすべて「行動を要求する」設計。怠惰な人はそもそも参加しない | 行動コストをほぼゼロ（写真を撮るだけ）にすれば、今まで誰も持っていなかった「沈黙の多数派」のリアルなインサイトが取得できる |
| **2** | **傲慢** | 自己評価の高い人々が大量の改善アイデアを持っているが、それがSNSで消費されて終わる | アイデアと企業の意思決定の間にルートがない。「いいね」が集まっても企業に届く仕組みがない | アイデアを企業の仕様書に変換するパイプラインを作れば、無報酬のクラウドソーシング型R&Dとして機能する |
| **3** | **短期** | 人は問題に遭遇した「その瞬間」に最もリアルなフラストレーションと改善意欲を持っている | 従来の調査は「後でアンケートを送る」「思い出して書く」が前提。短期思考者はエンゲージメントのピークが去ると答えない | 問題遭遇の瞬間に0.5秒で「理想の姿」を生成・共有させることで、エンゲージメントのピークを逃さず捕捉できる |
