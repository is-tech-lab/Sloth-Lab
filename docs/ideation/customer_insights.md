# Customer Insights — Refactor the World

## 1. ペルソナ（顧客像）

### ペルソナA：「罪悪感持ちのだらけ屋」（コアターゲット）

| 項目 | 内容 |
|------|------|
| 年齢 | 24歳 |
| 職業 | 社会人2年目（一般企業の事務・営業など） |
| 家族構成 | 一人暮らし |
| 趣味 | Netflix・SNS・ゴロゴロ（本当はもっと充実させたい） |
| 年収 | 280〜350万円 |
| SNS習慣 | Instagramで「意識高い投稿」を見ては自己嫌悪するのが習慣 |

**1日の簡単なスケジュール**
- 07:30 起床。「今日こそちゃんとやろう」と思って布団から出る
- 09:00 出勤。仕事自体はこなせている。サボっているわけじゃない
- 19:00 帰宅。「今日も頑張った。少し休もう」のつもりでスマホを開く
- 21:00 気づいたら2時間経っている。「あ、やろうと思ってたこと…」
- 23:00 「今日も何もできなかった」という罪悪感とともに就寝準備
- 00:30 罪悪感でなかなか寝付けず、またスマホを見てしまう

**だらけてしまう場面**
- 帰宅後の「ちょっと休憩」が2〜3時間になる
- 休日に「今日は何かしよう」と思っていたのに気づいたら夕方
- 締め切りギリギリまで手をつけられない
- 「やる気が出たらやろう」を繰り返して結局やらない

**罪悪感の具体的な中身**
- 「自分より頑張っている人がいるのに、自分はだらけている」
- 「このままじゃ成長できない、差がついていく」
- SNSで充実している人の投稿を見ては「自分はダメだ」と比べてしまう
- 休んでいるときに「休んでいい理由」を探してしまう

**本当はこうなりたい、という気持ち**
- 100%で動けなくてもいいと思いたいけど、思えない
- 「これでいい」と自分を許せるようになりたい
- だらけることに罪悪感を感じない日を過ごしてみたい

### ペルソナB：「ねじ曲がった優越感を持つだらけ屋」（サブターゲット）

| 項目 | 内容 |
|------|------|
| 年齢 | 28歳 |
| 職業 | 社会人5年目（IT・コンサル・広告など、成果が見えやすい職種） |
| 家族構成 | 一人暮らし |
| 年収 | 600万円 |
| 特徴 | 「本気を出せばできる」という確信があるため、だらけていても自己評価はそこまで下がらない。むしろ「本気出してないのにこれだけできてる自分」への歪んだ自負がある。でも本気を出す日は来ない。 |

**だらけ方の特徴**
- 「本気出せばもっとできるのに」が口癖だが、本気を出したことはここ数年ない
- 仕事はそこそこの成果を出しているので、だらけていることへの言い訳が成立してしまう
- 「今の70%でこれだけできてるんだから、俺って実は優秀じゃないか」と思っている
- 後輩や同期を「あいつら必死にやってやっと俺と同じか」と内心見下している

**罪悪感の歪み方**
- 罪悪感はあるが「でも自分なら本気出せばすぐ取り返せる」と上書きしてしまう
- 「本気を出していない自分」を責めるより、「本気を出していないのに結果を出せている自分」を誇りに思っている
- その構造に薄々気づいているが、認めると自己像が崩れるので直視しない

## 2. 行動分析 ——「だらける→罪悪感」のループがどこで起きるか

| 状態 | 日常の出現パターン | ペルソナAの具体的な行動 | 注目ポイント |
|------|-----------------|----------------------|------------|
| **だらける** | 休憩のつもりが止まらなくなる | 帰宅後スマホを「少しだけ」見るつもりが2時間経過。休日の「ゆっくりする朝」が夕方まで続く | 本人はサボっているつもりはなく「ちょっと休んでいるだけ」と思っている |
| **罪悪感** | だらけた後に自己評価が下がる | 「あー今日も何もできなかった」と寝る前に後悔。SNSの充実した投稿と自分を比べて落ち込む | この罪悪感こそがペルソナを苦しめている中心 |
| **過剰補正** | 罪悪感から「次こそは」と無理な計画を立てる | 「明日は早起きして全部やろう」と計画するが翌日もできず、またループへ | 罪悪感が解消されないまま繰り返す |

## 3. 改善インパクトが大きい課題 Top3

問い：**「頑張ってはいるけど100%ではない自分」を、なぜ許せないのか？**

| 順位 | 課題 | なぜ○○せずに□□ができないのか？ | 解決のカギ |
|------|------|-------------------------------|-----------|
| **1** | **だらけることへの罪悪感が消えない** | なぜ「休んでいい」と思えずに、休むたびに自分を責めてしまうのか？ | 「だらけること」に正当性・肯定感を与える言葉・体験・コミュニティ |
| **2** | **「充実している人」との比較で自己評価が下がる** | なぜ「自分のペースでいい」と思えずに、他人の頑張りを見て凹むのか？ | 比べる対象が変わる・「自分がすでに頑張っている」が見える仕組み |
| **3** | **罪悪感があるのに行動にはつながらない** | なぜ「罪悪感を持つこと」が行動改善ではなく自己消耗で終わってしまうのか？ | 罪悪感をエネルギーに変えるのではなく、そもそも罪悪感を持たなくていい状態にする |
