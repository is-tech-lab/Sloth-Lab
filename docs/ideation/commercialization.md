## 2. ビジネスモデルの検証

| 検証軸 | 評価 | 根拠 | 懸念点・改善案 |
|--------|------|------|--------------|
| ✓ **顧客の問題を解決しているか** | 🟢 YES | 課題Top3（即時ビジョン化・影響力断絶・承認遅延）すべてに対応 | 企業が本当に「採用」するかは実証が必要 |
| ✓ **コストまたは収益の改善につながるか** | 🟢 YES | 企業の市場調査コストを大幅削減（従来のユーザー調査費：数百万〜数千万円→データ購入費：月額数十万円） | データ品質・信頼性を担保する仕組みが必要 |
| ✓ **AIモデルの精度向上のためのデータ増加につながるか** | 🟢 YES | ユーザー生成の「問題画像×理想画像×社会的評価」データは、特化型モデルの学習データとして高価値 | プライバシー・権利処理（公共空間の写真に写り込む人物等）の課題あり |

**改善案：**
- 企業採用率を高めるため、初期は「スポンサー課題」モデルも検討（企業が「この課題のリファクタリングを募集」と出題、ユーザーが解答）
- データ品質担保のため、専門家レビューレイヤーを追加（建築家・デザイナーによるキュレーション）

## 3. PR/FAQ

---

### プレスリリース

# Refactor the World — 世界はバグだらけだ。君が書き換えろ。

**解決する課題**：「良いアイデアがあるのに、誰も動かない」を終わらせる。

**体験手順（3ステップ）：**

1. **Capture（捉える）**：街で見つけた「バグ」をスマホで撮影する
2. **Refactor（書き換える）**：AIが0.5秒で「あるべき姿」の画像を生成。自動バグレポートも作成
3. **Deploy（実装を見届ける）**：SNSに公開→企業がデータを購入→現実が変わっていくビルドログを監視

### FAQ

**Q: どのように評価されていますか？**
A: コミュニティの「いいね（Approve）」「プルリクエスト（改善提案）」「スタンプ（賛否表明）」の3指標で評価されます。高評価案は「Hot Issues」として企業の目に触れる優先枠に掲載されます。あなたのリファクタリング案が企業に採用された場合、実装報酬（インセンティブ）が支払われます。

**Q: 価格はいくらですか？**
A: ユーザー利用は**完全無料**です。AI生成は1日10件まで無料。プレミアムプラン（月額980円）でAI生成無制限・高解像度・影響力スコア詳細を利用できます。企業向けデータダッシュボードは月額50万円〜（地域・カテゴリに応じて変動）。

**Q: 競合との違いは？**
A: RoomGPTやCanvaは「個人の空間のリデザイン」ツールですが、RTWは「公共空間・社会インフラの不満を集合知として収集し、企業の意思決定データに変換する」点が本質的に異なります。ユーザーは「椅子から動かず世界に影響を与える」体験を得ます。Fix My Streetとの違いは、「問題報告」ではなく「解決ビジョンの生成と社会的承認」を軸にしている点です。
