## 3. X / Instagram との競合ポジション

### 企業向け：なぜX/InstagramのデータではなくRTWか

| 比較軸 | X / Instagram | RTW |
|--------|--------------|-----|
| データ構造 | 現状への反応（テキスト・写真）のみ | **現状画像 × 理想画像のbefore/afterペア**。「どうなってほしいか」が視覚的に構造化されている |
| 文脈の純度 | 投稿の意図が雑多（怒り・冗談・感想・改善提案が混在）。分類に高コスト | ユーザーが「リファクタリングする」という行為をした時点で**改善意図が保証**されている |
| 業種別活用 | 自社に無関係な投稿と混在。カテゴリ・地域での精度ある絞り込みが困難 | 業種・カテゴリ・地域・評価スコアで**構造化購入**が可能 |
| 企業の能動性 | タグ検索・モニタリングのみ。企業側から働きかけるルートがない | **スポンサー課題**で企業が能動的に「欲しいビジョン」を募集できる |
| **PoC** | 「誰が投稿したか」と「誰にテストさせるか」が紐付かない。PoC参加者を別途募集する必要がある | **ビジョン投稿者=PoC参加者**として直接招待できる。仮説（ビジョン）と検証（PoC）が同一人物で完結。参加者の動機も高い（自分が描いた理想を試せる） |

### ユーザー向け：なぜX/InstagramではなくRTWに書くか

| 比較軸 | X / Instagram | RTW |
|--------|--------------|-----|
| ビジョンの生成 | テキストか自撮り写真のみ。「こうなってほしい」を視覚化する手段がない | **AIが即座に理想画像を生成**。自分では作れないビジョンが形になる |
| 即時報酬 | いいねのみ（プラットフォームが利益を得る、ユーザーには金銭的報酬なし） | **投稿・評価獲得でポイント付与**。ポイントは報酬に換算できる |
| 承認の質 | 見知らぬフォロワーからのいいね | **「企業があなたのビジョンに注目しています」通知**。承認の重みが違う |
| 影響の実感 | 投稿しても現実は変わらない | 採用→実装→**ビルドログで進捗を追える**。「俺のアイデアが現実になった」体験 |
| 企業とのやり取り | 一方通行（@メンションしても企業はほぼ反応しない） | **企業から直接コメント・スポンサー課題の招待**が届く |
| 採用報酬 | なし | **採用されたら報酬**（ポイント換金 or キャッシュ） |

### RTWのエンゲージメントループ（X/Instagram流出を防ぐ設計）

```
日常で「もっとこうなれば」を感じる
        ↓
RTWアプリでカメラ撮影 → AI即時変換（アプリ内完結）
        ↓
RTWフィードに投稿
        ↓                           ↓
[ユーザーコミュニティ]           [企業ダッシュボード]
いいね / PR / スタンプ           閲覧・コメント・
        ↓                      スポンサー課題招待
ポイント付与                           ↓
        ↓                   「企業が注目中」通知 → ポイント
        ↓                           ↓
              採用決定 → 採用報酬（ポイント換金）
                              ↓
              【PoC招待】ビジョン投稿者=テスター
              自分が描いた理想を実際に試す
                              ↓
              フィードバック → 実装精度向上
                              ↓
              実装進捗をビルドログで追跡 → ローンチ
                              ↓
              また新しいビジョンを投稿（ループ継続）
```

このループがRTW内で完結し、かつビジョン投稿→PoC→フィードバック→再投稿の自己強化サイクルが回る。X/Instagramへの流出動機が生まれない。

## 4. PR/FAQ

### プレスリリース

# Refactor the World — 世界はバグだらけだ。君が書き換えろ。

**サービスの本質**：日常の何気ない風景を「もっとこうなればいいのに」に変える創造的衝動を、AIが0.5秒で形にする。そのビジョンは企業の目に直接届き、採用されればあなたに報酬が入る。

**体験手順（3ステップ）：**

1. **Capture（捉える）**：アプリを開き、気になったものをカメラで写す。壊れているものでなくていい。「なんとなく惜しい」「俺ならこうする」と思ったものなら何でも
2. **Refactor（書き換える）**：アプリ内でその場でぶっ壊す。実現可能性は関係ない。自分が頭の中で思い描いた理想の姿をAIが即座に生成する
3. **Deploy（世界に放つ）**：RTWに投稿してコミュニティと企業の評価を受ける。支持されれば企業から直接連絡が来て、採用されたら報酬が入る

### FAQ

**Q: どのように評価・報酬がもらえますか？**
A: 投稿するだけでポイントが付与されます。いいね・PRをもらうとさらにポイントが増えます。企業があなたのビジョンを閲覧・注目した際にも通知とポイントが入ります。ビジョンが採用された場合、採用報酬（ポイント換金またはキャッシュ）が支払われます。スポンサー課題（企業が賞金付きで募集）に採用されると、より大きな報酬が得られます。

**Q: 価格はいくらですか？**
A: ユーザー利用は**完全無料**です。AI生成は1日10件まで無料。プレミアムプラン（月額980円）でAI生成無制限・高解像度・影響力スコア詳細を利用できます。企業向けインサイトダッシュボードは月額50万円〜（業種・地域・カテゴリに応じて変動）。

**Q: X（Twitter）やInstagramと何が違うのですか？**
A: X/Instagramでは「こうなってほしい」という思いはテキストか写真でしか表現できません。RTWではAIが即座に理想の画像を生成します。また、X/Instagramではいくらいいねされてもユーザーへのお金の還元はなく、現実が変わることもありません。RTWは投稿でポイントが貯まり、企業から直接コメントが届き、採用されたら報酬が入る——「書き込むことに意味がある」プラットフォームです。

**Q: 競合他社との違いは？**
A: Fix My Streetは「壊れたものをゼロに戻す」問題報告プラットフォーム、RoomGPTは部屋限定の現実的リデザインツールです。RTWはカメラで写せるものすべてが対象で、実現可能性を度外視した創造的ビジョンを生成し、そのビジョンが企業に直接届いて採用される経路まで一気通貫しています。
