# Step2: アイディア発明

## 目的
参考事例を収集し、組み合わせて新しい解決策を発明する

## プロンプト

**前提**: Step1で作成した `aidlc-docs/ideation/customer_insights.md` を参照してください。

```
aidlc-docs/ideation/customer_insights.md を参照してください。

先ほど特定した課題を解決するアイディアを発明します。

1. 参考事例の収集
   Web検索や公開事例から、類似課題の解決事例を5つ探してください。
   各事例には以下を含めてください：
   - 概要
   - 技術的特徴（使用している生成AI技術）
   - ビジネス的特徴（収益モデル、顧客価値）

2. アイディアの発明
   収集した事例を2つ以上組み合わせて、新しい解決策を3つ発明してください。
   各アイディアには以下を含めてください：
   - アイディア名
   - 解決する課題（Step1の課題から選択）
   - 技術的アプローチ（どの生成AI技術を使うか）
   - 期待される効果（削減リソース、時間短縮など）
   - 実装難易度（低/中/高）

3. 最有望案の選択
   3つのアイディアから最も有望なものを1つ選び、理由を説明してください。
   選択基準：
   - 顧客インパクト（大きいほど良い）
   - 実装難易度（低いほど良い）
   - 独自性（競合との差別化）

表形式でまとめてください。

**重要**: 結果を `aidlc-docs/ideation/ideas.md` に保存してください。
```

## レビュー・修正フェーズ

生成された内容を確認し、以下の観点で自分で考えて修正してください：

- [ ] 参考事例は本当に参考になるか？他に良い事例はないか？
- [ ] 3つのアイディアは課題を解決できているか？
- [ ] 最有望案の選択理由は納得できるか？別の案の方が良くないか？
- [ ] 技術的に実現可能か？実装難易度の評価は適切か？

**必要に応じて `aidlc-docs/ideation/ideas.md` を直接編集してください。**

自分の直感や経験を信じて、AIの提案を批判的に見ることが重要です。

## 使い方

1. Step1の結果を確認
2. 上記プロンプトをコピー
3. Claude Code チャットに貼り付け
   - ターミナル: `claude` コマンドで起動
   - VSCode拡張 / Claude.ai デスクトップアプリでも利用可能
4. 出力結果を確認し、必要に応じて追加質問
