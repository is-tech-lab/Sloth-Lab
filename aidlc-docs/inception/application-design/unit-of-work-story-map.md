## ユニット別ストーリー詳細

### Unit 1 — Auth + IPファン識別基盤

#### US-001: 新規アカウント登録
- **ペルソナ**: ユイ（初回利用）、ケンタ（初回利用）
- **バリュー**: アカウントを作成することで、自分の「仕事じゃないけど」投稿を識別・蓄積できる
- **受け入れ基準（要点）**:
  - **AWS Cognito User Pool** に新規ユーザーが作成される
  - メール / パスワード / 名前（`custom:name`）を入力して登録できる（バリデーション：email RFC 5322 簡易、password Cognito ポリシー、name 1〜20文字）
  - **登録 UI 形態は PoC 実装時に決定**（Cognito Hosted UI / 自前フォームのいずれか）
  - 既登録メールで Cognito からエラー
  - 登録成功後、**Auth.js が HttpOnly Cookie にセッションを書き込む**
  - クライアントは `useSession()` で `{ id (Cognito sub), name (custom:name) }` を取得できる
  - タイムライン画面に遷移

#### US-002: ログイン
- **ペルソナ**: ユイ・ケンタ（2回目以降）
- **バリュー**: ログインで投稿・自分の投稿一覧・AIナマケモノとの関係性にアクセス
- **受け入れ基準（要点）**:
  - `signIn("cognito")` または Cognito Hosted UI でログインフローを開始
  - 正しい認証情報で **Cognito の InitiateAuth** が成功 → Auth.js がセッション Cookie を書き込み
  - クライアントは `useSession()` で `{ id, name }` を取得 → タイムラインへ遷移
  - 誤認証情報で Cognito からエラー

### Unit 2 — ナマケモノ対話エンジン（動的IPの核）

#### US-003: 「仕事じゃないけど」をそのまま投稿する
- **ペルソナ**: ユイ（怠惰系：「布団から出られず3時間スマホ見続けた」/善行系：「昼休みに親にLINEした」）、ケンタ（怠惰系：「会議中ぼーっとしてた」/善行系：「後輩をランチに誘った」）
- **バリュー**: 「仕事じゃないけど」と前置きできるすべての行動（**怠惰系・善行系両方**）が AI ナマケモノに 5経路紐付けで肯定される
- **受け入れ基準（要点）**:
  - テキスト入力欄からの送信
  - フィルタリング（仕事系除外）→ ナマケモノ応答の流れ
  - 怠惰系投稿も善行系投稿も**等しく通過**
  - サンドイッチUI でタイムライン反映

#### US-004: 仕事系投稿の除外フィードバック
- **ペルソナ**: ユイ・ケンタ（誤って仕事の話を投稿）
- **バリュー**: 「ここは仕事じゃないあなたの場所です」と理解し、仕事じゃない時間を投稿に切り替えられる
- **受け入れ基準（要点）**:
  - 仕事の成果・旅行・充実投稿が除外される
  - 除外時は Bedrock Claude が日本語の理由を生成（例：「仕事の成果はここでは扱いません。Sloth Feed は『仕事じゃないあなた』の場所です。怠惰でも善行でも、仕事じゃない時間を聞かせてください」）
  - 除外投稿はタイムラインに残らない

#### US-005: AI ナマケモノからの偉人引用付き肯定コメントを受け取る（**コア体験**）
- **ペルソナ**: ユイ（思想的肯定で罪悪感ループを断つ）、ケンタ（哲学アンカーで自己肯定補強）
- **バリュー**: 「仕事じゃない自分の時間は、人類が紡いできた営みの系譜にある」という思想的肯定で罪悪感ループから抜ける
- **受け入れ基準（要点）**:
  - Bedrock Claude が**5経路のいずれかに紐付けて**肯定コメントを生成（FR-003）
  - **【経路X】ラベル**が表示される（FR-011）
  - 偉人・哲学・科学引用付き（Larry Wall・ラッセル・老子・ニュートン・フレミング・ケインズ等）
  - 出典が明記される（PoC は LLM 自己申告。Phase 2 で S3 + Agentic Search 事実検証、FR-007 / NFR-005）
  - **「達観した怠惰の老師」人格**で応答（FR-010）：拒絶しない・比較しない・馴れ合い口調にしない・🦥 はヘッダラベルにのみ
  - 投稿とセットで DynamoDB に保存（aiCitationSource / pathway / authorName 含む）

#### US-006: AI ナマケモノとの関係性が継続する（個別化記憶）
- **ペルソナ**: ユイ（自分専用ナマケモノが育つ）、ケンタ（哲学的対話の蓄積）
- **バリュー**: 「自分専用のナマケモノが育っている」IP 体験
- **受け入れ基準（要点）**:
  - AI ナマケモノが過去投稿（UserHistory）を参照（FR-006）
  - 「先週、布団から出られなかったあなたへ」のような継続性のあるコメント
  - ペルソナごとの応答トーン差別化

#### US-009: AI ナマケモノから切り上げ提案を受け取る（依存防止）
- **ペルソナ**: ユイ（罪悪感ループから抜けたい一方で依存リスク）、ケンタ（理屈で正当化しがちなため切り上げが救う）
- **バリュー**: 「ダメ礼賛」が新たな依存を生むダーク・パターンに陥らず、健全に距離を取れる
- **受け入れ基準（要点）**:
  - 連続投稿 5件 / 滞在 30分超で切り上げ提案（PoC 仮値）
  - 「達観した怠惰の老師」人格で自然な口調（説教調・警告調にしない）
  - 切り上げ提案はユーザーを遮断しない（投稿継続可能）
  - 無視されても繰り返し説教しない

### Unit 3 — 共同体タイムライン（サンドイッチUI）

#### US-007: 全ユーザーのタイムラインを閲覧する
- **ペルソナ**: ユイ（他人の「仕事じゃないけど」を見て「私だけじゃない」）
- **バリュー**: 「みんな仕事じゃないことをやって生きている」という共同体感
- **受け入れ基準（要点）**:
  - 未ログインで閲覧可能
  - 全ユーザー投稿が新しい順（PoC 最近 50件）
  - **サンドイッチUI**（上「仕事じゃないけど」/ 中：投稿+AIコメント / 下「これが世の中を変える」）
  - **【経路X】ラベル**が表示される（FR-011）
  - フォロワー数・いいね数・ランキングは一切表示しない

#### US-008: 自分の「仕事じゃないけど」の蓄積を振り返る
- **ペルソナ**: ユイ（夜寝る前に振り返り）、ケンタ（自分の賢明な怠惰と気遣いの歴史）
- **バリュー**: 「こんなに仕事じゃないことをやってきたんだ」という自己肯定感
- **受け入れ基準（要点）**:
  - 自分の投稿のみが新しい順
  - 各投稿にテキスト・AIコメント・引用元・経路ラベル・投稿日時
  - スタンプ数・いいね数は**そもそも存在しない**
