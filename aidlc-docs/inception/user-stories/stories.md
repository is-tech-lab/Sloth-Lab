# ユーザーストーリー — Sloth Feed

> **本ドキュメントの前提（2026-05-09 更新）**
> Issue #5 帰着により、投稿対象は**「真の怠惰・無為・サボり」**と**「小さな善行」**の**両方を等しく扱う**。「立派な小さな善行だけ称賛」（旧フレーム）と「ダメ全振り」のどちらにも偏らない。AIナマケモノが偉人・科学・歴史引用付きで**5経路のいずれかに紐付けて肯定**する**動的IP × AI技術**を中核に据えている。

**分解アプローチ**: ユーザージャーニーベース
**投稿者識別**: メール+パスワード認証
**フィルタリングフィードバック**: Claude APIが除外理由を生成
**肯定機能**: AI ナマケモノが Larry Wall・ラッセル・老子等の引用付き肯定コメントを生成

---

## Journey 1: アカウント登録・ログイン

### US-001: 新規アカウント登録
**As** 初めてSloth Feedを使うユーザーとして
**I want** メールアドレスとパスワードでアカウントを作成したい
**So that** 自分のダメ投稿を識別・蓄積できるようになる

**受け入れ基準**
- [ ] メールアドレスとパスワードを入力してアカウントを作成できる
- [ ] 既に登録済みのメールアドレスで登録しようとするとエラーが表示される
- [ ] 登録成功後、タイムライン画面に遷移する

**ペルソナ**: ユイ・ケンタ両方
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

## Journey 2: ダメを投稿する

### US-003: 「仕事じゃないけど」をそのまま投稿する
**As** ログイン済みのユーザーとして
**I want** 「**仕事じゃないけど**」と前置きできるすべての行動——**怠惰系も善行系も等しく**——をテキストで投稿したい
**So that** その時間が「世の中を変える行動」として AI ナマケモノに5経路のいずれかに紐付けて肯定される

**受け入れ基準**
- [ ] テキスト入力欄に文章を入力して投稿ボタンを押せる
- [ ] 投稿前に AI フィルタリング（仕事の成果・キラキラ充実投稿の除外）が実行される（ローディング表示あり）
- [ ] フィルタリング通過後、AI ナマケモノが**5経路のいずれかに紐付けて**偉人・科学・歴史引用付きで肯定コメントを生成して表示する
- [ ] 怠惰系投稿（「布団から出られなかった」）も善行系投稿（「彼に洗い物しといた」）も**等しく通過**する
- [ ] 投稿が**サンドイッチUI**でタイムラインに反映される

**ペルソナ**: ユイ（怠惰系：「布団から出られず3時間スマホ見続けた」/善行系：「昼休みに親にLINEした」）、ケンタ（怠惰系：「会議中ぼーっとしてた」/善行系：「後輩をランチに誘った」）
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

---

### US-004: 仕事系投稿の除外フィードバックを受け取る
**As** 投稿が除外されたユーザーとして
**I want** **「ここはダメを誇る場所です」**というメッセージを AI から受け取りたい
**So that** Sloth Feed のコンセプト（仕事系投稿は対象外）を理解して、ダメ投稿に切り替えられる

**受け入れ基準**
- [ ] 仕事の成果・旅行・充実投稿がフィルタリングで除外される
- [ ] 除外時、Claude API が生成した日本語のメッセージが表示される（例：「**仕事の成果はここでは扱いません。Sloth Feed はダメを誇る場所です。あなたの『ダメだった』を聞かせてください**」）
- [ ] 除外された投稿はタイムラインに追加されない
- [ ] ユーザーは入力欄をクリアして再入力できる

**ペルソナ**: ユイ（誤って「プレゼン褒められた」と投稿してしまう）、ケンタ（「成果出した」を投稿しようとして弾かれる）
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

## Journey 3: AI ナマケモノに肯定される

### US-005: AI ナマケモノからの偉人引用付き肯定コメントを受け取る（**コア体験**）
**As** ダメ投稿がフィルタリングを通過したユーザーとして
**I want** AI ナマケモノが Larry Wall・ラッセル・老子・ニュートン・フレミング等の**偉人引用付き**で自分のダメを肯定するコメントをくれること
**So that** 「ダメな自分は、人類の怠惰の系譜にある」という思想的肯定を得て、罪悪感ループから抜けられる

**受け入れ基準**
- [ ] 投稿通過後、Claude API が投稿内容に応じた肯定コメントを生成する
- [ ] コメントには**偉人・哲学・科学のいずれかの引用**が含まれる
  - 例（怠惰系）：「**Larry Wall は『怠惰こそ最大の美徳』と説いた。あなたは今日それを実践した**」
  - 例（哲学系）：「**老子は『為さざるを為す』と書いた。あなたのその時間こそ、最も強い作為である**」
  - 例（科学系）：「**フレミングは休暇でラボを離れていた間にペニシリンを発見した。あなたの3時間も、何かを醸成しているかもしれない**」
- [ ] コメントには**出典が明記**される（ハルシネーション防止のため）
- [ ] コメントは投稿とセットで DynamoDB に保存される
- [ ] タイムラインで他ユーザーの投稿にも AI ナマケモノコメントが表示される

**ペルソナ**: ユイ（思想的肯定で罪悪感ループを断ち切る）、ケンタ（哲学アンカーで自己肯定を補強）
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

---

### US-006（新規）: AI ナマケモノとの関係性が継続する
**As** 継続して使うユーザーとして
**I want** AI ナマケモノが**過去の自分のダメ投稿を覚えていて**、継続性のある対話をしてくれること
**So that** 「自分専用のナマケモノが育っている」という IP 体験を得られる

**受け入れ基準**
- [ ] AI ナマケモノが過去の投稿履歴を参照して応答する
- [ ] 「先週、布団から出られなかったあなたへ」のような継続性のあるコメントが生成される
- [ ] ユーザーごとに異なるトーンの応答が生成される（ペルソナA向け：優しく / ペルソナB向け：哲学的に）

**ペルソナ**: ユイ（「先週も布団から出られなかったあなたを覚えていますよ」）、ケンタ（「またあなたの賢明な怠惰を聞かせてください」）
**INVEST**: Independent ⚠️ (US-005 に依存) / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

## Journey 4: タイムラインを見る

### US-007: 全ユーザーのダメタイムラインを閲覧する
**As** ログイン済みのユーザーとして
**I want** 全ユーザーの「ダメだった」投稿をタイムラインで見たい
**So that** 「**みんなダメで生きている**」という共同体感を得て、自分だけじゃないと安心できる

**受け入れ基準**
- [ ] 全ユーザーの投稿が新しい順に表示される
- [ ] 各投稿が**サンドイッチUI**で表示される（上部「仕事じゃないけど」/ 中央：投稿 + AI コメント / 下部「これが世の中を変える」）
- [ ] フォロワー数・いいね数・ランキングは**一切表示されない**
- [ ] 未ログイン状態でもタイムラインにアクセスできる

**ペルソナ**: ユイ（他人のダメを見て「私だけじゃない」と感じる）
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

## Journey 5: 自分のダメを振り返る

### US-008: 自分のダメ投稿の蓄積を振り返る
**As** ログイン済みのユーザーとして
**I want** 自分のこれまでのダメ投稿と AI ナマケモノからの肯定コメントを一覧で振り返りたい
**So that** 「**こんなにダメで生きてきたんだ**」という、自分のダメの蓄積による自己肯定感を得られる

**受け入れ基準**
- [ ] 自分の投稿のみが新しい順に一覧表示される
- [ ] 各投稿にはテキスト・AI ナマケモノコメント・投稿日時・**引用元**が表示される
- [ ] 他ユーザーの投稿は表示されない
- [ ] スタンプ数・いいね数は**そもそも存在しない**（旧 `stamps` フィールド削除済み）

**ペルソナ**: ユイ（「こんなにダメで生きてこれた」）、ケンタ（「自分の賢明な怠惰の歴史」）
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

## 旧版からの主な変更点

| 項目 | 旧版 | 新版 |
|---|---|---|
| 投稿対象 | 「仕事じゃないけど立派な小さな善行」のみ（卵買った、母にLINEした等）| **「真の怠惰・無為・サボり」と「小さな善行」の両方**（布団3時間／彼に洗い物／昼休みに親にLINE 等を等しく扱う）|
| AIコメントの形式 | 「ハーバードの研究では小さな親切が…」（自己啓発系）| **5経路に紐付け**て、偉人・科学・歴史引用付きで「**何が、どう、世の中を変えるのか**」を具体的に言語化 |
| AIコメントの位置づけ | 称賛コメント | **動的IP（AIナマケモノ）からの個別化された5経路肯定** |
| 投稿テンプレート強制 | 「仕事じゃないけど」prefix 強制 | prefix強制を撤回、UI のサンドイッチ構造で担保 |
| US-006（新規）| なし | **AI ナマケモノとの関係性継続**（個別化記憶）|
| ストーリー数 | 7（US-001〜007）| **8（US-001〜008、US-006 新規追加）**|
