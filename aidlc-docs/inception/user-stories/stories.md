# User Stories — Refactor the World (RTW) MVP

## 概要

| 項目 | 選択 |
|------|------|
| **整理アプローチ** | ユーザージャーニーベース |
| **粒度** | ストーリーのみ（エピック階層なし） |
| **受け入れ基準フォーマット** | Given / When / Then（BDD形式） |
| **AI変換UX** | ローディング画面シンプル |
| **変換後フロー** | 確認あり＋再変換対応 |
| **優先度** | [P0] AIコア体験 / [P1] 投稿・フィード・認証 / [P2] マイページ |
| **エラーケース** | 各ストーリーの受け入れ基準（非ハッピーパス）に記述 |
| **ペルソナ** | 共通ストーリー＋ Persona A/B 視点メモ |

**合計**: 13 ストーリー

---

## ジャーニー 1: 登録・ログイン（FR-01）

### US-01 [P1] — 新規ユーザー登録

**As a** 新規ユーザーとして、  
**I want to** メールアドレスとパスワードでアカウントを作成したい  
**so that** RTWプラットフォームを利用開始できる。

> **Persona A**: 仕事の合間に1分以内で登録完了したい。ソーシャルログイン不要。
> **Persona B**: SNSアプリを始める感覚で簡単に登録できればいい。

**Acceptance Criteria**

*ハッピーパス*
- **Given** 未登録のユーザーがアプリを起動している
  **When** メールアドレス・パスワード・ユーザー名を入力して「登録」をタップする
  **Then** アカウントが作成され、フィード画面に遷移する
  **And** JWTトークンが発行されセッションが開始される

*エラーケース*
- **Given** 登録フォームを開いている
  **When** すでに使用済みのメールアドレスで登録しようとする
  **Then** 「このメールアドレスはすでに使用されています」エラーメッセージが表示される

- **Given** 登録フォームを開いている
  **When** パスワードが8文字未満で登録しようとする
  **Then** 「パスワードは8文字以上で設定してください」エラーが表示される

- **Given** 登録フォームを開いている
  **When** メールアドレスの形式が不正（@なし等）で登録しようとする
  **Then** 「有効なメールアドレスを入力してください」エラーが表示される

---

### US-02 [P1] — ログイン

**As a** 登録済みユーザーとして、  
**I want to** メールアドレスとパスワードでログインしたい  
**so that** 自分のアカウントでRTWを利用できる。

> **Persona A**: アプリを再起動してもすぐ使える状態にしたい。
> **Persona B**: 毎回ログインが不要なら嬉しい（セッション維持）。

**Acceptance Criteria**

*ハッピーパス*
- **Given** ログアウト状態のユーザーがログイン画面を開いている
  **When** 正しいメールアドレスとパスワードを入力して「ログイン」をタップする
  **Then** 認証が完了し、フィード画面に遷移する
  **And** JWTトークンが発行されセッションが維持される

*エラーケース*
- **Given** ログイン画面を開いている
  **When** 存在しないメールアドレスまたは誤ったパスワードを入力してログインしようとする
  **Then** 「メールアドレスまたはパスワードが正しくありません」エラーが表示される
  **And** パスワードフィールドがクリアされる

---

### US-03 [P1] — ログアウト

**As a** ログイン中のユーザーとして、  
**I want to** ログアウトしたい  
**so that** 自分のアカウントへのアクセスを安全に終了できる。

> **Persona A**: 共用デバイスを使う場面はないが、アカウント切り替えのために使う可能性がある。
> **Persona B**: 特にシナリオなし。設定画面にあれば十分。

**Acceptance Criteria**

*ハッピーパス*
- **Given** ログイン中のユーザーが設定画面を開いている
  **When** 「ログアウト」をタップし、確認ダイアログで「はい」を選択する
  **Then** JWTトークンが削除され、ログイン画面に遷移する

## ジャーニー 2: カメラ撮影（FR-02）

### US-04 [P0] — アプリ内カメラで写真を撮る

**As a** ログイン中のユーザーとして、  
**I want to** アプリ内のカメラで写真を撮影したい  
**so that** その場でリファクタリングしたいシーンをすぐキャプチャできる。

> **Persona A**: 通勤中や外出先でパッと撮影してすぐAI変換に進みたい。
> **Persona B**: TikTok感覚でその場の直感をすぐ形にしたい。

**Acceptance Criteria**

*ハッピーパス*
- **Given** ログイン中のユーザーがホーム画面（またはカメラボタン）にいる
  **When** カメラボタンをタップし、カメラの権限を許可する
  **Then** アプリ内カメラが起動する
  **When** シャッターボタンをタップする
  **Then** 撮影した写真がプレビュー表示され、「この写真を使う」「撮り直す」の選択肢が表示される
  **When** 「この写真を使う」をタップする
  **Then** AI変換画面に遷移し、撮影画像が before 画像としてセットされる

*エラーケース*
- **Given** カメラボタンをタップした
  **When** カメラの権限が拒否されている
  **Then** 「カメラへのアクセスを許可してください（設定アプリから変更できます）」メッセージが表示される

---

### US-05 [P0] — カメラロールから画像を選ぶ

**As a** ログイン中のユーザーとして、  
**I want to** カメラロールから既存の写真を選んでAI変換に使いたい  
**so that** 以前撮影した写真でもリファクタリングできる。

> **Persona A**: 会議や現場視察の写真を後から変換するケースに使う。
> **Persona B**: 撮り溜めていたインスピレーション写真を変換したい。

**Acceptance Criteria**

*ハッピーパス*
- **Given** ログイン中のユーザーがカメラ起動画面にいる
  **When** 「カメラロールから選ぶ」をタップし、写真ライブラリへのアクセスを許可する
  **Then** カメラロールが表示される
  **When** 1枚の写真を選択する
  **Then** 選択した写真がプレビュー表示され、「この写真を使う」「選び直す」の選択肢が表示される
  **When** 「この写真を使う」をタップする
  **Then** AI変換画面に遷移し、選択画像が before 画像としてセットされる

*エラーケース*
- **Given** 「カメラロールから選ぶ」をタップした
  **When** 写真ライブラリへのアクセスが拒否されている
  **Then** 「写真ライブラリへのアクセスを許可してください（設定アプリから変更できます）」メッセージが表示される

## ジャーニー 3: AI変換（FR-03）

### US-06 [P0] — 撮影した写真をAI変換する

**As a** before画像がセットされたユーザーとして、  
**I want to** 写真をAI変換（Refactor）したい  
**so that** 現実のシーンの「理想の姿」をafter画像として見ることができる。

> **Persona A**: 「課題→理想」の変換精度が高いほど良い。10秒待てる。
> **Persona B**: 生成される絵に「おおっ」という驚きがあれば満足。

**Acceptance Criteria**

*ハッピーパス*
- **Given** before画像がセットされたAI変換画面にいる
  **When** 「Refactor（変換）」ボタンをタップする
  **Then** ローディングインジケーターが表示され、変換処理が開始される
  **And** 変換処理は10秒以内に完了する
  **When** 処理が完了する
  **Then** before画像とafter画像が並べて表示される
  **And** 「投稿する」「やり直す」「キャンセル（破棄）」の選択肢が表示される

*エラーケース*
- **Given** AI変換処理中である
  **When** OpenAI APIのエラーまたはタイムアウト（10秒超）が発生する
  **Then** 「変換に失敗しました。もう一度お試しください」エラーメッセージが表示される
  **And** 「やり直す」ボタンが表示される

- **Given** AI変換処理中である
  **When** ネットワーク接続が切断される
  **Then** 「通信エラーが発生しました。接続を確認してください」メッセージが表示される
  **And** 「やり直す」ボタンが表示される

---

### US-07 [P0] — 変換結果を確認して再変換する

**As a** AI変換結果を確認中のユーザーとして、  
**I want to** after画像が気に入らない場合に再変換したい  
**so that** 納得のいくビジョンを投稿できる。

> **Persona A**: ビジョンの解像度にこだわりたい。2〜3回試す可能性がある。
> **Persona B**: お気に入りの仕上がりが出るまで何度か試したい。

**Acceptance Criteria**

*ハッピーパス*
- **Given** before/after画像が並べて表示されている
  **When** 「やり直す」をタップする
  **Then** 確認ダイアログ「変換をやり直しますか？（APIリクエストが再度発生します）」が表示される
  **When** 「やり直す」を確認する
  **Then** ローディングインジケーターが表示され、新しい変換処理が開始される
  **And** 新しいafter画像が生成されて before/after 画像が更新される

- **Given** before/after画像が並べて表示されている
  **When** 「キャンセル（破棄）」をタップする
  **Then** 撮影・選択前の画面（カメラ起動画面）に戻り、変換データは破棄される

---

## ジャーニー 4: 投稿（FR-04）

### US-08 [P1] — before/afterペアをカテゴリタグ付きで投稿する

**As a** 変換結果に満足したユーザーとして、  
**I want to** before/afterペアにカテゴリタグを付けてRTWフィードに投稿したい  
**so that** 自分のビジョンをRTWコミュニティに公開できる。

> **Persona A**: タグはカテゴリを示す重要な情報。「仕事・インフラ」系を選ぶ。
> **Persona B**: タグはノリで選ぶ。「食事」「インテリア」など日常系。

**Acceptance Criteria**

*ハッピーパス*
- **Given** before/after画像を確認中のユーザーが「投稿する」をタップした
  **When** 投稿画面が表示される
  **Then** カテゴリタグ選択UI（食事・街・インテリア・その他）が表示される
  **When** カテゴリタグを1つ選択して「投稿する」をタップする
  **Then** before/after画像ペアがRTWフィードに投稿される
  **And** 自分のマイページの投稿一覧に表示される
  **And** 投稿完了画面またはフィード画面に遷移する

*エラーケース*
- **Given** 投稿処理中である
  **When** ネットワークエラーまたはサーバーエラーが発生する
  **Then** 「投稿に失敗しました。もう一度お試しください」エラーが表示される
  **And** 入力内容は保持されたまま再試行できる

## ジャーニー 5: フィード閲覧（FR-05）

### US-09 [P1] — RTWフィードをスクロールして投稿を閲覧する

**As a** ログイン中のユーザーとして、  
**I want to** 他のユーザーのbefore/after投稿をフィードでスクロール閲覧したい  
**so that** 他者のリファクタリングビジョンを楽しめる。

> **Persona A**: 他のビジョンを見てビジネスインサイトを得たり、クオリティの高い投稿に刺激をもらう。
> **Persona B**: TikTok感覚で無限スクロールして楽しむ。

**Acceptance Criteria**

*ハッピーパス*
- **Given** ログイン中のユーザーがフィード画面を開く
  **When** フィードが表示される
  **Then** 他ユーザーの投稿（before画像・after画像・ユーザー名・カテゴリタグ・いいね数）が新着順に表示される
  **And** 初回表示は3秒以内に完了する
  **When** スクロールダウンする
  **Then** 追加の投稿が読み込まれる（페이지ネーション）

*エラーケース*
- **Given** フィード画面を開こうとしている
  **When** ネットワーク接続がない
  **Then** 「フィードを読み込めませんでした。接続を確認してください」エラーが表示される

- **Given** フィードが正常に表示されている
  **When** 投稿が1件も存在しない（初期状態）
  **Then** 「まだ投稿がありません。最初のリファクタリングをしてみよう！」の空状態メッセージが表示される

---

## ジャーニー 6: いいね（FR-06）

### US-10 [P1] — 投稿にいいねをつける

**As a** フィードを閲覧中のユーザーとして、  
**I want to** 気に入った投稿にいいねをつけたい  
**so that** 投稿者にビジョンへの共感を伝えられる。

> **Persona A**: 質の高いビジョン・インサイトへの共鳴として使う。
> **Persona B**: ノリとセンスで反応。TikTokのハートと同じ感覚。

**Acceptance Criteria**

*ハッピーパス*
- **Given** フィード上の投稿を見ているユーザーが、まだいいねしていない投稿にいる
  **When** いいねボタン（ハートアイコン）をタップする
  **Then** いいねが記録され、いいね数が1増加する
  **And** ハートアイコンが「いいね済み」状態（色が付く等）に変わる

*エラーケース*
- **Given** いいねボタンをタップした
  **When** ネットワークエラーが発生する
  **Then** エラーメッセージが表示され、いいね数の変化は反映されない
  **And** ボタンは元の「未いいね」状態に戻る

---

### US-11 [P1] — いいねを取り消す

**As a** いいねした投稿があるユーザーとして、  
**I want to** いいねを取り消したい  
**so that** 誤タップや気が変わった場合に修正できる。

> **Persona A**: 誤タップの修正として使う。
> **Persona B**: 気が変わったときにサッと取り消せればいい。

**Acceptance Criteria**

*ハッピーパス*
- **Given** すでにいいねした投稿のいいねボタンが「いいね済み」状態になっている
  **When** いいねボタンをもう一度タップする
  **Then** いいねが取り消され、いいね数が1減少する
  **And** ハートアイコンが「未いいね」状態に戻る

---

## ジャーニー 7: マイページ（FR-07）

### US-12 [P2] — 自分の投稿一覧を確認する

**As a** ログイン中のユーザーとして、  
**I want to** マイページで自分の投稿一覧を確認したい  
**so that** これまでにリファクタリングしたビジョンを振り返れる。

> **Persona A**: ポートフォリオとして活用したい。良いビジョンを後から見返す。
> **Persona B**: たまに見返す程度。いくつ投稿したかを確認する。

**Acceptance Criteria**

*ハッピーパス*
- **Given** ログイン中のユーザーがマイページを開く
  **When** 「投稿」タブを表示する（または初期表示が投稿一覧の場合）
  **Then** 自分が投稿したbefore/afterペアの一覧が新着順に表示される
  **And** 各投稿にカテゴリタグといいね数が表示される

*エラーケース*
- **Given** マイページの投稿一覧を開いた
  **When** 自分の投稿が0件
  **Then** 「まだ投稿がありません。最初のリファクタリングをしてみよう！」の空状態メッセージが表示される

---

### US-13 [P2] — 自分がいいねした投稿一覧を確認する

**As a** ログイン中のユーザーとして、  
**I want to** マイページで自分がいいねした投稿一覧を確認したい  
**so that** 気に入ったビジョンをあとからまとめて見返せる。

> **Persona A**: 良いビジョンを保存先として使う。あまり頻繁には使わない。
> **Persona B**: 好きなビジョンをコレクションしてたまに見返す。インスピレーション源として使う。

**Acceptance Criteria**

*ハッピーパス*
- **Given** ログイン中のユーザーがマイページを開く
  **When** 「いいね」タブをタップする
  **Then** 自分がいいねした投稿の一覧が表示される
  **And** いいねした日時の降順（最近いいねしたものが上）で表示される

*エラーケース*
- **Given** マイページの「いいね」タブを開いた
  **When** いいねした投稿が0件
  **Then** 「まだいいねした投稿がありません」の空状態メッセージが表示される

## MVPスコープ境界（明示的除外）

以下はMVPのスコープ外であり、これらのユーザーストーリーは存在しない：

| 除外機能 | 理由 |
|---------|------|
| ポイント付与・交換 | 後続フェーズ（usersテーブルにpoints列のみ予約） |
| 企業ダッシュボード | 後続フェーズ |
| スポンサー課題 | 後続フェーズ |
| PoC支援マッチング | 後続フェーズ |
| 採用報酬 | 後続フェーズ |
| プッシュ通知 | MVPスコープ外 |
| フォロー・フォロワー | MVPスコープ外 |
| コメント機能 | MVPスコープ外 |
| 推薦アルゴリズム（フィード） | MVPはシンプル新着順 |
