# ユーザーストーリー — Sloth Feed

> 最新版：2026-05-09 / 改訂履歴は [`audit.md`](../../audit.md) と [`aidlc-state.md`](../../aidlc-state.md) を参照。
>
> 投稿対象は **真の怠惰・無為・サボり** と **小さな善行** の両方を等しく扱う。AI ナマケモノが偉人・科学・歴史引用付きで**5経路のいずれかに紐付けて肯定**する**動的IP × AI技術**を中核に据える。
> 認証は **Auth.js (NextAuth v5) + AWS Cognito User Pool**。詳細は `application-design/component-methods.md` の「Authentication & Identity Flow」セクション参照。

**分解アプローチ**: ユーザージャーニーベース
**投稿者識別**: メール+パスワード認証
**フィルタリングフィードバック**: Bedrock Claudeが除外理由を生成
**肯定機能**: AI ナマケモノが Larry Wall・ラッセル・老子等の引用付き肯定コメントを生成

---

## Journey 1: アカウント登録・ログイン

### US-001: 新規アカウント登録
**As** 初めてSloth Feedを使うユーザーとして
**I want** メールアドレスとパスワードでアカウントを作成したい
**So that** 自分の「仕事じゃないけど」投稿を識別・蓄積できるようになる

**受け入れ基準**
- [ ] **AWS Cognito User Pool** に新規ユーザーが作成される（メール / パスワード / `custom:name`）
- [ ] 登録 UI 形態は PoC 実装時に決定（Cognito Hosted UI / 自前フォーム）
- [ ] 入力バリデーション：email RFC 5322 簡易、password は Cognito ポリシー、name 1〜20文字
- [ ] 既に登録済みのメールアドレスで登録しようとすると Cognito からエラー
- [ ] 登録成功後、**Auth.js が HttpOnly Cookie にセッションを書き込む**
- [ ] クライアントは `useSession()` で `{ id (Cognito sub), name }` を取得できる
- [ ] タイムライン画面に遷移する

**ペルソナ**: ユイ・ケンタ両方
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

---

### US-002: ログイン
**As** 登録済みのユーザーとして
**I want** メールアドレスとパスワードでログインしたい
**So that** 自分の「仕事じゃないけど」投稿履歴と AI ナマケモノとの関係性にアクセスできる

**受け入れ基準**
- [ ] `signIn("cognito")` または Cognito Hosted UI でログインフローを開始できる
- [ ] 正しい認証情報で **Cognito の InitiateAuth** が成功 → **Auth.js がセッション Cookie を書き込む**
- [ ] クライアントは `useSession()` で `{ id, name }` を取得できる
- [ ] 誤った認証情報では Cognito からエラーが返り、ログインできない
- [ ] ログイン成功後、タイムライン画面に遷移する

**ペルソナ**: ユイ・ケンタ両方
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

## Journey 2: 「仕事じゃないけど」を投稿する

### US-003: 「仕事じゃないけど」をそのまま投稿する
**As** ログイン済みのユーザーとして
**I want** 「**仕事じゃないけど**」と前置きできるすべての行動——**怠惰系も善行系も等しく**——をテキストで投稿したい
**So that** その時間が「世の中を変える行動」として AI ナマケモノに5経路のいずれかに紐付けて肯定される

**受け入れ基準**
- [ ] テキスト入力欄に文章を入力して投稿ボタンを押せる
- [ ] 投稿前に AI フィルタリング（仕事の成果・キラキラ充実投稿の除外）が実行される（ローディング表示あり）
- [ ] フィルタリング通過後、AI ナマケモノが**5経路のいずれかに紐付けて**偉人・科学・歴史引用付きで肯定コメントを生成して表示する
- [ ] 怠惰系投稿（「布団から出られなかった」）も善行系投稿（「彼に洗い物しといた」）も**等しく通過**する
- [ ] 投稿が**サンドイッチUI**でタイムラインに反映される

**ペルソナ**: ユイ（怠惰系：「布団から出られず3時間スマホ見続けた」/善行系：「昼休みに彼にLINEした」）、ケンタ（怠惰系：「会議中ぼーっとしてた」/善行系：「後輩をランチに誘った」）
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

---

### US-004: 仕事系投稿の除外フィードバックを受け取る
**As** 投稿が除外されたユーザーとして
**I want** **「ここは仕事じゃないあなたの場所です」**というメッセージを AI から受け取りたい
**So that** Sloth Feed のコンセプト（仕事系投稿は対象外）を理解して、「仕事じゃないけど」投稿に切り替えられる

**受け入れ基準**
- [ ] 仕事の成果・旅行・充実投稿がフィルタリングで除外される
- [ ] 除外時、Bedrock Claude が生成した日本語のメッセージが表示される（例：「**仕事の成果はここでは扱いません。Sloth Feed は『仕事じゃないあなた』の場所です。怠惰でも善行でも、仕事じゃない時間を聞かせてください**」）
- [ ] 除外された投稿はタイムラインに追加されない
- [ ] ユーザーは入力欄をクリアして再入力できる

**ペルソナ**: ユイ（誤って「プレゼン褒められた」と投稿してしまう）、ケンタ（「成果出した」を投稿しようとして弾かれる）
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

## Journey 3: AI ナマケモノに肯定される

### US-005: AI ナマケモノからの偉人引用付き肯定コメントを受け取る（**コア体験**）
**As** 「仕事じゃないけど」投稿がフィルタリングを通過したユーザーとして
**I want** AI ナマケモノが Larry Wall・ラッセル・老子・ニュートン・フレミング等の**偉人引用付き**で自分の「仕事じゃないけど」（怠惰でも善行でも）を肯定するコメントをくれること
**So that** 「仕事じゃない自分の時間は、人類が紡いできた営みの系譜にある」という思想的肯定を得て、罪悪感ループから抜けられる

**受け入れ基準**
- [ ] 投稿通過後、Bedrock Claude が投稿内容に応じた肯定コメントを生成する
- [ ] AI ナマケモノコメント先頭に**【経路X】ラベル**が表示される（経路①〜⑤のいずれか。FR-011 参照）
  - 例：「🦥 ナマケモノからのひとこと【経路①過剰生産社会へのブレーキ】」
- [ ] コメントには**偉人・哲学・科学のいずれかの引用**が含まれる
  - 例（怠惰系）：「**Larry Wall は『怠惰こそ最大の美徳』と説いた。あなたは今日それを実践した**」
  - 例（哲学系）：「**老子は『為さざるを為す』と書いた。あなたのその時間こそ、最も強い作為である**」
  - 例（科学系）：「**フレミングは休暇でラボを離れていた間にペニシリンを発見した。あなたの3時間も、何かを醸成しているかもしれない**」
- [ ] コメントには**出典が明記**される（PoC では LLM の自己申告ベース。Phase 2 で S3 + Agentic Search による事実検証を予定。FR-007 / NFR-005 参照）
- [ ] AI ナマケモノは**「達観した怠惰の老師」人格**で応答する（FR-010 参照）：
  - **DO**：「**それで結構**」「**それで十分**」「**悪くない**」のような**静かな肯定**で結ぶ／**柔らかな断定**（〜である／〜だろう）／**長期視点**（歳月を重ねればわかる／100年経てば）／**簡素で密度の高い文**・余白あり／文頭の相槌は控えめに（「ふむ」「そうか」は3〜4投稿に1回）
  - **DO（追加）**：`🦥` ナマケモノ絵文字は**ヘッダラベル（「🦥 ナマケモノからのひとこと【経路X】」）にのみ使う**（本文中には入れない）
  - **DON'T**：投稿を**拒絶しない**（怠惰・善行どちらでも肯定）／他ユーザーと**比較しない**／**馴れ合い口調**にしない（「〜だね♪」「〜ですよ〜」）／**時代劇調**にしない（「お主」「〜じゃ」）／**世代対立**を持ち込まない／**本文に絵文字・顔文字を散りばめない**／**現代スラング**（「マジで」「ヤバい」等）は使わない
- [ ] コメントは投稿とセットで DynamoDB に保存される
- [ ] タイムラインで他ユーザーの投稿にも AI ナマケモノコメントが表示される

**ペルソナ**: ユイ（思想的肯定で罪悪感ループを断ち切る）、ケンタ（哲学アンカーで自己肯定を補強）
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

---

### US-006: AI ナマケモノとの関係性が継続する
**As** 継続して使うユーザーとして
**I want** AI ナマケモノが**過去の自分の「仕事じゃないけど」投稿を覚えていて**、継続性のある対話をしてくれること
**So that** 「自分専用のナマケモノが育っている」という IP 体験を得られる

**受け入れ基準**
- [ ] AI ナマケモノが過去の投稿履歴を参照して応答する
- [ ] 「先週、布団から出られなかったあなたへ」のような継続性のあるコメントが生成される
- [ ] ユーザーごとに異なるトーンの応答が生成される（ペルソナA向け：優しく / ペルソナB向け：哲学的に）

**ペルソナ**: ユイ（「先週も布団から出られなかったあなたを覚えていますよ」）、ケンタ（「またあなたの賢明な怠惰を聞かせてください」）
**INVEST**: Independent ⚠️ (US-005 に依存) / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

## Journey 4: タイムラインを見る

### US-007: 全ユーザーの「仕事じゃないけど」タイムラインを閲覧する
**As** ログイン済みのユーザーとして
**I want** 全ユーザーの「仕事じゃないけど」投稿をタイムラインで見たい
**So that** 「**みんな仕事じゃないことをやって生きている**」という共同体感を得て、自分だけじゃないと安心できる

**受け入れ基準**
- [ ] 全ユーザーの投稿が新しい順に表示される
- [ ] 各投稿が**サンドイッチUI**で表示される（上部「仕事じゃないけど」/ 中央：投稿 + AI コメント / 下部「これが世の中を変える」）
- [ ] 各投稿の AI ナマケモノコメント部分に**【経路X】ラベル**が表示される（FR-011 参照）
  - タイムラインを見るユーザーは、他人の「仕事じゃないけど」がどの経路で世の中を変えたかを一覧で把握できる
- [ ] フォロワー数・いいね数・ランキングは**一切表示されない**
- [ ] 未ログイン状態でもタイムラインにアクセスできる

**ペルソナ**: ユイ（他人の「仕事じゃないけど」を見て「私だけじゃない」と感じる）
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

## Journey 5: 自分の「仕事じゃないけど」を振り返る

### US-008: 自分の「仕事じゃないけど」の蓄積を振り返る
**As** ログイン済みのユーザーとして
**I want** 自分のこれまでの「仕事じゃないけど」投稿と AI ナマケモノからの肯定コメントを一覧で振り返りたい
**So that** 「**こんなに仕事じゃないことをやってきたんだ**」という、自分の「仕事じゃない時間」の蓄積による自己肯定感を得られる

**受け入れ基準**
- [ ] 自分の投稿のみが新しい順に一覧表示される
- [ ] 各投稿にはテキスト・AI ナマケモノコメント・投稿日時・**引用元**が表示される
- [ ] 他ユーザーの投稿は表示されない
- [ ] スタンプ数・いいね数は**そもそも存在しない**

**ペルソナ**: ユイ（「こんなに仕事じゃないことをやってこれた」）、ケンタ（「自分の賢明な怠惰と気遣いの歴史」）
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

## Journey 6: 健全に離れる

### US-009: AI ナマケモノから「そろそろ寝ましょう」と切り上げ提案を受け取る
**As** Sloth Feed を連続使用しているユーザーとして
**I want** 一定時間使い続けた／連続して投稿した時に、AI ナマケモノから「**そろそろ寝ましょう**」「**ダメで終わるのも美徳です**」のような切り上げ提案を受け取りたい
**So that** 「ダメ礼賛」が新たな依存を生むダーク・パターンに陥ることなく、健全に Sloth Feed と距離を取れる

**受け入れ基準**
- [ ] 連続投稿が一定数（PoC では仮に **5件**）を超えた場合、次の投稿への AI コメントに**切り上げ提案**が含まれる
- [ ] 連続滞在時間が一定（PoC では仮に **30分**）を超えた場合、AI ナマケモノが切り上げ提案を表示する
- [ ] 切り上げ提案は **「達観した怠惰の老師」人格**（FR-010 参照）で行われる（説教調・警告調にしない・上から目線にしない）
  - 例（ヘッダ + 本文の構成）：
    - ヘッダ：「🦥 ナマケモノからのひとこと（一服）」
    - 本文：「ふむ、今日はもう5本目だ。老子は『為さざるを為す』と書いた——休むのも作為のうち。**そろそろ寝ましょう**。明日また、何もしなくていい。」
  - 例：
    - ヘッダ：「🦥 ナマケモノからのひとこと（一服）」
    - 本文：「ここまで読んでくれてありがとう。今日のあなたはもう十分だ。**ダメで終わるのも美徳である**。」
- [ ] 切り上げ提案は**ユーザーを遮断しない**（投稿そのものは可能、画面ロックもしない）
- [ ] ユーザーが切り上げを無視して継続使用しても、ナマケモノは**繰り返し説教しない**

**ペルソナ**: ユイ（罪悪感ループから抜けたい一方で、Sloth Feed への依存リスクがある）、ケンタ（理屈で正当化しがちなため、ナマケモノからの切り上げが彼を救う）
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

**実装メモ**: 閾値（5件 / 30分）は PoC 用の仮値。実装時にユーザビリティテストで調整。NFR-005（AI 出力の倫理性）と直接連動する機能要件 FR-009 のストーリー化。
