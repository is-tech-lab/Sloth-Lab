# Sloth-Lab ユーザーストーリー

## 前提・方針
- **分解アプローチ**: ユーザージャーニーベース（初回起動 → コアタップ体験 → ウィジェット閲覧）
- **PoC優先**: 受け入れ基準はハッカソンデモが動くことを最低ラインとする
- **タップ方式**: ウィジェット自体からタップ可能（iOS 17+ インタラクティブウィジェット）
- **認証**: 位置情報許可ダイアログのみ。アカウント登録なし、匿名デバイスID

---

## ジャーニー 1: 初回起動フロー

### US-01: 位置情報の許可
**ペルソナ**: 田中 翔（怠惰ワーカー）、佐藤 美咲（育児疲れ会社員）

> **As a** 初めてSloth-Labを起動したユーザー  
> **I want** 位置情報の利用許可を求めるダイアログを見て許可する  
> **So that** 近くの同志を検知するサービスを利用できるようになる

**受け入れ基準:**
- [ ] アプリ初回起動時にApple標準の位置情報許可ダイアログが表示される
- [ ] 許可した場合、アプリがGPS位置情報を取得できる状態になる
- [ ] 拒否した場合、位置情報が取得できない旨をシンプルに表示し、設定から変更できることを案内する
- [ ] 2回目以降の起動では許可ダイアログは表示されない

## ジャーニー 2: 「だるい」コアタップ体験

### US-02: ウィジェットからの「だるい」送信
**ペルソナ**: 田中 翔（メインペルソナ）

> **As a** ホーム画面のSloth-Labウィジェットを見ているユーザー  
> **I want** ウィジェット上の「だるい」ボタンをタップする  
> **So that** アプリを開かずにワンタップで自分の「だるい」状態を送信できる

**受け入れ基準:**
- [ ] ホーム画面ウィジェットに「だるい」ボタン（またはタップ可能なキャラクター）が表示される
- [ ] ウィジェットをタップすると現在のGPS位置情報とタイムスタンプがバックエンドAPIに送信される
- [ ] 送信はアプリを開かずにウィジェットから完結できる（iOS 17+ AppIntent を使用）
- [ ] 送信中・送信完了の視覚的フィードバックがある（例：ウィジェットが一瞬変化する）

### US-03: 近接「だるい」同志数の取得・表示
**ペルソナ**: 田中 翔、佐藤 美咲

> **As a** 「だるい」をタップしたユーザー  
> **I want** 半径3km以内の「だるい」状態にある人の数を知る  
> **So that** 「自分だけじゃない」という安心感を得られる

**受け入れ基準:**
- [ ] タップ後、バックエンドAPIが半径3km以内・直近30分以内にタップしたユーザー数を返す
- [ ] 取得した人数がウィジェットに表示される（例：「3人が一緒にだるい」）
- [ ] 自分自身はカウントに含まれない（または含まれることが明示される）
- [ ] 0人の場合も自然に表示される（例：「今は1人…でも気にしない」）

### US-04: キャラクターの増殖表示
**ペルソナ**: 田中 翔、佐藤 美咲

> **As a** 近接同志数を確認したユーザー  
> **I want** 同志の数に応じてウィジェット上のキャラクターが増えるのを見る  
> **So that** 数字ではなくビジュアルで「仲間がいる感覚」を楽しめる

**受け入れ基準:**
- [ ] 同志数0: キャラクターが1体（自分のみ）表示される
- [ ] 同志数1〜3: キャラクターが2〜4体表示される
- [ ] 同志数4以上: キャラクターが5体以上（上限あり）表示される、または数字で補足される
- [ ] キャラクターの増減がウィジェットの更新に合わせて反映される

## ジャーニー 3: ウィジェット閲覧フロー

### US-05: ホーム画面での常時表示
**ペルソナ**: 田中 翔、佐藤 美咲

> **As a** Sloth-Labをホーム画面に追加したユーザー  
> **I want** アプリを開かずにホーム画面で現在の近接同志数を確認する  
> **So that** 気づいたときにすぐ「仲間のいる感覚」を得られる

**受け入れ基準:**
- [ ] WidgetKit ウィジェットがホーム画面に追加できる
- [ ] ウィジェットに現在の近接同志数とキャラクターが表示される
- [ ] アプリが起動していない状態でもウィジェットが表示される

### US-06: ウィジェットの自動更新
**ペルソナ**: 田中 翔、佐藤 美咲

> **As a** Sloth-Labウィジェットをホーム画面に置いているユーザー  
> **I want** ウィジェットの表示が自動的に最新の近接人数に更新される  
> **So that** 常に最新の「だるい」同志状況を確認できる

**受け入れ基準:**
- [ ] WidgetKit のタイムライン更新機能により、定期的にバックエンドAPIを呼び出す
- [ ] 更新間隔はシステムポリシーに準拠（目安：15〜30分）
- [ ] 「だるい」タップ直後はウィジェットが即時更新される（AppIntentによるreloadTimelines）

1. iPhoneのホーム画面を見せる → Sloth-Labウィジェットが表示されている
2. ウィジェットの「だるい」をタップ → 別のiPhone（チームメンバーが持つ）もタップ
3. ウィジェットの人数が増える → キャラクターが増殖する
