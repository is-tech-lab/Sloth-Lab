# ユーザーストーリー — Sloth Feed

**分解アプローチ**: ユーザージャーニーベース  
**投稿者識別**: メール+パスワード認証  
**フィルタリングフィードバック**: Claude APIが除外理由を生成  
**称賛機能**: AIが偉人の功績・論文を元に一言コメントを生成（スタンプなし）

---

## Journey 1: アカウント登録・ログイン

### US-001: 新規アカウント登録
**As** 初めてSloth Feedを使うユーザーとして  
**I want** メールアドレスとパスワードでアカウントを作成したい  
**So that** 自分の投稿を識別・管理できるようになる

**受け入れ基準**
- [ ] メールアドレスとパスワードを入力してアカウントを作成できる
- [ ] 既に登録済みのメールアドレスで登録しようとするとエラーが表示される
- [ ] 登録成功後、タイムライン画面に遷移する

**ペルソナ**: ユイ・ケンタ両方  
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

---

### US-002: ログイン
**As** 登録済みのユーザーとして  
**I want** メールアドレスとパスワードでログインしたい  
**So that** 自分の投稿履歴にアクセスできる

**受け入れ基準**
- [ ] 正しいメールアドレスとパスワードでログインできる
- [ ] 誤った認証情報ではログインできず、エラーが表示される
- [ ] ログイン成功後、タイムライン画面に遷移する

**ペルソナ**: ユイ・ケンタ両方  
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

## Journey 2: 投稿する

### US-003: 「仕事じゃないけど」を投稿する
**As** ログイン済みのユーザーとして  
**I want** 「仕事じゃないけど」やった行動を写真/動画/テキストで投稿したい  
**So that** 自分の行動が正当化・肯定される体験を得られる

**受け入れ基準**
- [ ] テキスト入力欄に文章を入力して投稿ボタンを押せる
- [ ] 投稿送信後、AIフィルタリングが実行される（ローディング表示あり）
- [ ] フィルタリング通過後、AIコメントが生成されて表示される
- [ ] 投稿がタイムラインに反映される

**ペルソナ**: ユイ（「帰り道に卵買っといた」）、ケンタ（「後輩をランチに誘った」）  
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

---

### US-004: フィルタリング除外時のフィードバックを受け取る
**As** 投稿が除外されたユーザーとして  
**I want** 除外された理由をAIから簡潔に教えてもらいたい  
**So that** 「なぜ使えないのか」を理解した上で別の投稿を試せる

**受け入れ基準**
- [ ] 仕事の成果・旅行・充実投稿がフィルタリングで除外される
- [ ] 除外時、Claude APIが生成した理由メッセージが表示される（例：「仕事の成果に関する投稿はここでは使えません。ここは"仕事じゃないけど"の場所です」）
- [ ] 投稿はタイムラインに追加されない
- [ ] ユーザーは入力欄をクリアして再入力できる

**ペルソナ**: ユイ（「今日プレゼンで褒められた」→除外される）  
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

---

## Journey 3: AIコメントを受け取る

### US-005: 投稿へのAI称賛コメントを受け取る
**As** 投稿がフィルタリングを通過したユーザーとして  
**I want** 偉人の功績や研究論文を引用したAIの一言コメントをもらいたい  
**So that** 「仕事じゃない自分の行動に価値がある」という実感を得られる

**受け入れ基準**
- [ ] 投稿通過後、Claude APIが投稿内容に応じた称賛コメントを生成する
- [ ] コメントは偉人の名言・研究・論文のいずれかを引用した形式で表示される
  - 例：「ハーバードの研究によると、小さな親切の積み重ねが精神的幸福に最も寄与するとされています。あなたは今日それを実践しました。」
- [ ] コメントは投稿直後に表示され、自分の投稿とセットで保存される
- [ ] タイムラインでは他ユーザーの投稿にもAIコメントが表示される

**ペルソナ**: ユイ（AIに肯定されることで就寝前の罪悪感ループを断ち切る）、ケンタ（論文引用で自己認識を確認する）  
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

## Journey 4: タイムラインを見る

### US-006: 全ユーザーのタイムラインを閲覧する
**As** ログイン済みのユーザーとして  
**I want** 全ユーザーの「仕事じゃないけど」投稿をタイムラインで見たい  
**So that** 「みんな同じだ」という安心感を得られる

**受け入れ基準**
- [ ] 全ユーザーの投稿が新しい順に表示される
- [ ] 各投稿にはテキスト・AIコメント・投稿日時が表示される
- [ ] フォロワー数・いいね数・ランキングは一切表示されない
- [ ] 未ログイン状態ではタイムラインにアクセスできない（ログイン画面にリダイレクト）

**ペルソナ**: ユイ（他人の「仕事じゃないけど」を見て「私だけじゃない」と感じる）  
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅

---

## Journey 5: 自分の投稿を振り返る

### US-007: 自分の過去投稿を振り返る
**As** ログイン済みのユーザーとして  
**I want** 自分のこれまでの投稿とAIコメントを一覧で振り返りたい  
**So that** 「仕事じゃない自分がこれだけやってきた」という記録を実感できる

**受け入れ基準**
- [ ] 自分の投稿のみが新しい順に一覧表示される
- [ ] 各投稿にはテキスト・AIコメント・投稿日時が表示される
- [ ] 他ユーザーの投稿は表示されない

**ペルソナ**: ユイ（「こんなに仕事じゃないことをやってきたんだ」と気づく）、ケンタ（自分の行動の積み重ねを確認する）  
**INVEST**: Independent ✅ / Negotiable ✅ / Valuable ✅ / Estimable ✅ / Small ✅ / Testable ✅
