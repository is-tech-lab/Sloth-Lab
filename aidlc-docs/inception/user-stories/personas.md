# Sloth-Lab ユーザーペルソナ

---

## ペルソナ 1: 怠惰ワーカー「田中 翔」（メインペルソナ）

| 項目 | 内容 |
|------|------|
| **年齢** | 32歳 |
| **職業** | ITエンジニア（在宅勤務） |
| **居住地** | 東京都23区内 |
| **デバイス** | iPhone 15（iOS 17+） |

### 特性・背景
- 週4〜5日在宅勤務。自室にこもりがちで孤独感を感じやすい
- 「今日もなんか動けない…自分だけがダメなのかな」と思うことが多い
- SNSは疲れるので最近ほとんど見ない
- スマホのホーム画面はよく確認する（通知チェックのクセ）

### 動機・ゴール
- 自分が「怠惰である」ことへの罪悪感を和らげたい
- 「みんな同じか」と知るだけで気持ちが軽くなる
- 手間をかけずに（アプリを開かずに）確認したい

### ペインポイント
- アプリを開くのが面倒くさい（特にだるいとき）
- SNSを見ると逆に「頑張ってる人」が目に入って落ち込む

### Sloth-Labとの関わり
- ホーム画面ウィジェットをチラ見して同志数を確認する
- 「だるい」ウィジェットボタンをその場でタップして参加する

## ペルソナ 2: 育児疲れ会社員「佐藤 美咲」（サブペルソナ）

| 項目 | 内容 |
|------|------|
| **年齢** | 37歳 |
| **職業** | マーケター（育休復帰後・時短勤務） |
| **居住地** | 神奈川県横浜市 |
| **デバイス** | iPhone 14（iOS 17+） |

### 特性・背景
- 子育てと仕事の両立でつねに何かに疲れている
- 「だるい」と思うことに罪悪感があるが、正直な気持ちでもある
- SNSは「映え」が辛くなって離れた

### 動機・ゴール
- 「みんな疲れてる、自分だけじゃない」という安心感がほしい
- スキマ時間（授乳中・通勤中）に一瞬で確認したい

### ペインポイント
- 複雑な操作やアプリ起動は面倒
- プライバシーが気になる（位置情報をどこまで使うか）

### Sloth-Labとの関わり
- ウィジェットをホーム画面に置いて、気づいたときにタップ
- キャラが増えていると「よかった」と安心する

## ペルソナ 3: ハッカソン審査員「鈴木 健一」（デモペルソナ）

| 項目 | 内容 |
|------|------|
| **年齢** | 44歳 |
| **職業** | AWS Japan シニアエンジニア |
| **背景** | AWS Summit Japan 2026 ハッカソン審査員 |

### 評価視点
- ユニークなコンセプトと技術的な実装の組み合わせを評価
- AWS サービス（DynamoDB, Lambda等）の活用度を見る
- デモが直感的で「わかりやすいか」を重視

### Sloth-Labとの関わり
- 発表時に複数iOSデバイスでデモを見る
- ウィジェットボタンタップ → 人数増加 → キャラ増殖の流れを体験する
