## ペルソナA：ユイ（罪悪感持ちのだらけ屋）

**コアターゲット**

| 属性 | 内容 |
|------|------|
| 名前 | 田中 ユイ（24歳）|
| 職業 | 社会人2年目・一般企業の営業事務 |
| 年収 | 300万円 |
| 生活 | 都内で同い年の彼氏と同棲2年目。恋人との関係性で仕事のパフォーマンスにムラがある。喧嘩中は仕事が手につかず、仲直りしたくて仕事中にLINEしてしまう |
| SNS習慣 | Instagramで充実した人の投稿を見ては自己嫌悪するのが毎晩の習慣 |

**行動パターン**
- 帰宅後「少し休憩」のつもりがスマホを2時間見てしまう
- 「今日も何もできなかった」と寝る前に後悔する
- 布団から出られない朝が多い
- 録画を一気見してしまう
- 「休んでいい理由」を探し続けている

**Sloth Feedへの動機**
- 「布団から3時間出られなかった」も「彼に洗い物しといた」も、**仕事じゃないけど**と前置きして投稿したい
- AIナマケモノに「**何が、どう、世の中を変えるのか**」を5経路で具体的に言語化してほしい
- 罪悪感なく眠れる夜がほしい
- 怠惰も善行も、無理に振り分けずに受け入れてもらいたい

**代表的な投稿（怠惰系・善行系の混合）**
> 怠惰系：
> - 「**布団から出られず、3時間スマホ見続けた**」
> - 「**二度寝して結局昼まで起きられなかった**」
>
> 善行系：
> - 「**彼に気づいて洗い物しといた**」
> - 「**昼休みに彼にLINEした**」
> - 「**帰り道に植物に水あげた**」

→ どちらも「**仕事じゃないけど**」の集合に等しく含まれ、AIナマケモノが5経路のいずれかを紐付けて肯定する。

## ペルソナB：ケンタ（ねじ曲がった優越感を持つだらけ屋）

**サブターゲット**

| 属性 | 内容 |
|------|------|
| 名前 | 鈴木 ケンタ（28歳）|
| 職業 | 社会人5年目・ITコンサルタント |
| 年収 | 600万円 |
| 生活 | 実家暮らし（両親・妹と同居）。仕事はそこそこの成果を出しているが、諦め癖がある。壁にぶつかると「今日じゃなくていいか」と家族のことが気になり始める。一方で「本気出せばもっとできる」という優越感が同居する |
| 口癖 | 「まあ、これくらいでいいか」 |

**行動パターン**
- 「今の70%でこれだけできてる俺、実は優秀では？」と思っている
- 後輩が必死にやって自分と同じ成果を出すのを内心見下している
- 罪悪感を「本気出せばすぐ取り返せる」で上書きしてしまう

**Sloth Feedへの動機**
- AIナマケモノが**Larry Wall や老子・脳科学を引用しながら自分の「仕事じゃない領域の動き」の知性を裏付けてくれる**こと
- 怠惰でも善行でも、**KPIに評価されない領域での自分**の真価をわかってもらいたい
- 後輩のような上っ面の称賛ではなく、**思想的アンカー付きの肯定**がほしい
- 他のユーザーと比較されないこと（ランキング・数字なし）

**代表的な投稿（怠惰系・善行系の混合）**
> 怠惰系：
> - 「**会議中ぼーっとしてた。気づいたら30分経ってた**」
> - 「**本気出さずに納品した**」
>
> 善行系：
> - 「**後輩がしんどそうだったのでランチに誘った**」
> - 「**打ち合わせ前にホワイトボード消しといた**」

→ 怠惰も善行も、ケンタにとっては「**KPIで評価されない領域の自分**」という意味で同列。AIナマケモノが両者を5経路で同等に肯定する。

## 二人に共通する核心ニーズ

両ペルソナの本音を一文に：

> **「仕事じゃない自分（怠惰でも善行でも）に、思想と AI による具体的肯定がほしい」**

- ユイは「仕事じゃない自分（だらけ・気遣い両方）を許してほしい」
- ケンタは「仕事じゃない自分（賢明な怠惰・KPI外の貢献両方）の知性を裏付けてほしい」

→ どちらもAIナマケモノが**5経路のいずれかに紐付けてLarry Wall・ラッセル・老子・脳科学・統計の引用付きで具体的に肯定する**ことで、本質的なニーズに応えられる。**怠惰でも善行でも分け隔てなく、5経路で扱う**。
