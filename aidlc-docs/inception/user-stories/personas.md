# ペルソナ定義 — Sloth Feed

---

## ペルソナA：ユイ（罪悪感持ちのだらけ屋）

**コアターゲット**

| 属性 | 内容 |
|------|------|
| 名前 | 田中 ユイ（24歳） |
| 職業 | 社会人2年目・一般企業の営業事務 |
| 年収 | 300万円 |
| 生活 | 都内一人暮らし。仕事はこなせているが、だらけることに強い罪悪感がある |
| SNS習慣 | Instagramで充実した人の投稿を見ては自己嫌悪するのが毎晩の習慣 |

**行動パターン**
- 帰宅後「少し休憩」のつもりがスマホを2時間見てしまう
- 「今日も何もできなかった」と寝る前に後悔する
- 「休んでいい理由」を探し続けている

**Sloth Feedへの動機**
- 「仕事じゃないけど、同棲してる彼に気づいて洗い物しといた」を誰かに認めてほしい
- AIに「あなたのその行動には意味がある」と言ってほしい
- 罪悪感なく眠れる夜がほしい

**代表的な投稿**
> 「仕事じゃないけど、帰り道に明日の朝ごはんのこと考えて卵買っといた」
> 「仕事じゃないけど、昼休みに母親にLINEした」

## ペルソナB：ケンタ（ねじ曲がった優越感を持つだらけ屋）

**サブターゲット**

| 属性 | 内容 |
|------|------|
| 名前 | 鈴木 ケンタ（28歳） |
| 職業 | 社会人5年目・ITコンサルタント |
| 年収 | 600万円 |
| 生活 | 都内一人暮らし。仕事はそこそこの成果を出しているが、本気を出したことはここ数年ない |
| 口癖 | 「本気を出せばもっとできる」 |

**行動パターン**
- 「今の70%でこれだけできてる俺、実は優秀では？」と思っている
- 後輩が必死にやって自分と同じ成果を出すのを内心見下している
- 罪悪感を「本気出せばすぐ取り返せる」で上書きしてしまう

**Sloth Feedへの動機**
- 「仕事以外の自分の行動の本当の価値をわかってるのはここだけだ」という感覚がほしい
- AIが引用する論文や偉人のコメントで、自分の正しさを確認したい
- 「さすが」と言われることに意義を感じている

**代表的な投稿**
> 「仕事じゃないけど、後輩が悩んでるの見てランチ誘った」
> 「仕事じゃないけど、打ち合わせ前に会議室のホワイトボード消しといた」
