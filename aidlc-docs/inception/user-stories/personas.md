# Personas — Refactor the World (RTW) MVP

## 概要

RTW MVPの主要ユーザーペルソナ。共通ストーリーに対してそれぞれの視点・利用シーンが異なる。

---

## Persona A — 「アーキテクト気質の不満族」

| 項目 | 詳細 |
|------|------|
| **名前** | 田中 凛（たなか りん） |
| **年齢** | 26歳 |
| **職業** | プロダクトマネージャー（テック系スタートアップ）|
| **居住地** | 東京・渋谷区 |
| **デバイス** | iPhone 15 Pro |
| **SNS利用** | Twitter/X（情報収集）、LinkedIn（キャリア）、Notion（個人メモ） |

### 特性

**動機（Goals）**
- 日常の「もっとこうなればいいのに」という直感を形にしたい
- 自分のアイデアが社会に届く実感を得たい
- 企業に対してユーザーとして直接インプットできる手段が欲しい

**フラストレーション（Frustrations）**
- X/TwitterやSlackでアイデアを書いても誰も拾わない
- 社内の会議で「面白いね」と言われるだけで何も動かない
- SNS投稿は3日後には流れ去り、誰の記憶にも残らない

**3つの心理変質との関係**
- **怠惰**: 業務が忙しく、改善アイデアがあっても書いて終わりになりがち → スマホ1枚で完結するなら試せる
- **短期**: SNS投稿のエンゲージメントが一瞬で消えることへの不満 → 企業から評価されて形に残る報酬が欲しい
- **傲慢**: 「このサービスはこうすべきだ」という自信があるが伝達手段がない → 企業に直接届く構造に価値を感じる

### RTW 利用シナリオ

```
朝の通勤電車でオフィスビルのエレベーター前の混雑に気づく
→ スマホを取り出してその場でパシャッと撮影
→ AI変換で「受付デジタル化・事前チェックインで分散入室」のビジョン画像が生成される
→ 「これ、うちのビルのオーナーに見せたい」と投稿
→ フィードに上がり、いいねが集まり始める
→ 数日後、ビル管理会社からPoCの打診通知が来る（MVP外だが想定動線）
```

**US マッピング**: US-01, US-02, US-04, US-06, US-07, US-08, US-09, US-10, US-12

## Persona B — 「ゆるクリエイティブな日常発信者」

| 項目 | 詳細 |
|------|------|
| **名前** | 鈴木 そら（すずき そら） |
| **年齢** | 19歳 |
| **職業** | 大学生（デザイン系学部 2年） |
| **居住地** | 東京・中野区 |
| **デバイス** | iPhone 15 |
| **SNS利用** | TikTok（主力）、Instagram（写真）、BeReal（日常） |

### 特性

**動機（Goals）**
- 日常の「なんかダサいな」「もっとオシャレになれそう」という感覚をすぐ表現したい
- SNS的な感覚でクリエイティブなコンテンツを気軽に作りたい
- 自分のセンスが認められてリアクションが返ってくる体験が好き

**フラストレーション（Frustrations）**
- InstagramやTikTokは作り込みが必要で疲れる
- 「いいね」はもらえても実際には何も変わらない
- アイデアはあるが、デザインスキルが追いつかない

**3つの心理変質との関係**
- **怠惰**: 長文を書いたり複雑な操作を覚えるのは続かない → カメラ1枚でAIが補完してくれる手軽さがちょうどいい
- **短期**: TikTokのバイラル感が好き。その場で完結する体験を求めている → AI変換の驚き体験が即時報酬になる
- **傲慢**: デザインセンスへの自信 → AIが自分のビジョンを形にしてくれる

### RTW 利用シナリオ

```
大学のカフェテリアのプラスチック食器を見て「もっとオシャレにできるのに」とふと思う
→ 食器の写真をパシャッと撮影
→ AI変換で「サステナブルな木製・陶器セット、テーブルに小植物」のビジョンが出てくる
→ 「いい感じ！」と投稿
→ 同じ大学の他学生がいいね。学生運動として盛り上がり始める（想定動線）
```

**US マッピング**: US-01, US-02, US-04, US-05, US-06, US-07, US-08, US-09, US-10, US-11, US-13
