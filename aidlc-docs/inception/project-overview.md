# Project Overview — Sloth Feed

> **Intent（事業意図・1文）**
> Sloth Feed は、**「人をダメにする」を旗印とする動的IP プロダクト**である。AI ナマケモノが、Larry Wall・ラッセル・老子の系譜から**ユーザーの怠惰そのものを肯定する**動的応答を返し、罪悪感ループから人々を解放する。SNS は IP の入口・コミュニティ装置であり、本業は IPの育成（物販・ライセンス・コラボ・出版）である。

> 最新版：2026-05-09 / 改訂履歴は [`audit.md`](../audit.md) と [`aidlc-state.md`](../aidlc-state.md) を参照。

---

## ビジョン

> **『仕事じゃないけど、、、』が世の中を変える**
> 「**ダメだけど、世の中を変える**」

**「人をダメにする」運動**——人類は、サボりたい欲望によって機械を発明し、楽をしたい怠惰によって自動化を編み出した。**ダメであることこそ、人類がここまで来た理由そのものだ。**

それなのに私たちは、毎晩「今日もダメだった」と自分を責めている。
Sloth Feed は、その逆を行く。あなたの「布団から出られなかった3時間」を、人類史の連続線の上に置く。

ただし、ただ「それは偉業だ」と褒めるのではない。**何が、どう、世の中を変えるのか**を、AIナマケモノは具体的に語る。

---

## ビジョンを支える5経路 ―ダメが世の中を変えるメカニズム

「ダメ」は5つの具体的な経路で世の中を変える。AIナマケモノは投稿内容に応じて、いずれかの経路を選び、ユーザーの行動を**そのメカニズムに紐付けて**肯定する。

### 経路①：過剰生産社会へのブレーキ

> あなたが何もしなかった時間、社会全体の過剰生産が確実にその分だけ減った。

24時間生産命令の現代社会への小さな・確実な抵抗。一人のサボりは0.0001%でも、何百万人が集まれば文化規範を変える。

### 経路②：創造の余白の保持（人間性の最後の砦）

> あなたの「何もしない」時間こそ、AIに代替されない人間性そのもの。

DMN（デフォルト・モード・ネットワーク）が活性化するのは、ぼんやりしている時。AIが「働く」を肩代わりできる時代に、人間の優位性は「**サボりながら考える**」こと。

### 経路③：多様性の保護

> あなたの存在が、「頑張る一強」社会への選択肢を一つ守った。

全員が「頑張る側」になると、生き方の多様性が消失する。ダメ仲間が可視化されることで、社会の選択肢が維持される。

### 経路④：自己への暴力の停止

> あなたが罪悪感を捨てた瞬間、現代のメンタルヘルス危機が一人分後退した。

罪悪感ループは個人の自己消耗 = 集合では社会的損失。「自分を許す」ことが、社会全体の精神的健康に寄与する。

### 経路⑤：集積による文化変容

> あなたの小さなダメは、社会のテンポを下げる集合運動の1ピース。

個人レベルのダメは小さい。しかし**集積**することで、社会のリズム・文化規範が変わる。一人の二度寝は事件ではないが、500万人の二度寝は労働政策を動かす。

### 5経路の関係

```
ダメな行動（投稿内容）
  ↓
AIナマケモノがいずれかの経路を選択
  ↓
具体的メカニズムを言語化（数字・科学・歴史を引用）
  ↓
「あなたの何が、どう、世の中を変えるのか」が伝わる
  ↓
罪悪感ループの構造的解放
```

## コンセプト

**「仕事じゃないあなた」を、AI と思想で構造的に肯定する動的IPプロダクト。**

- 投稿対象：**仕事じゃない行動すべて**——両方を等しく扱う：
  - **真の怠惰・無為・サボり**（布団から3時間出られない、二度寝、録画一気見）
  - **小さな善行**（家族にLINE、洗い物、植物に水やり）
- 弾かれるのは**仕事の成果・旅行・キラキラ充実投稿**のみ
- AI ナマケモノが、偉人・哲学・科学の引用付きで肯定する（5経路のいずれかに紐付け）
- タイムラインに比較・競争は存在しない。あるのは「みんなの仕事じゃないけど」だけ

Instagram が「充実した自分」を演じる場所なら、
**Sloth Feed は「仕事じゃない自分」をそのまま出せる場所。**

## コアバリュー

| バリュー | 意味 |
|---------|------|
| **No Hustle, No Apology** | ダメを正当化するために、言い訳はいらない |
| **Lazy = World-Changing** | 怠惰こそが文明を進歩させてきた |
| **No Comparison** | 数字・ランキング・フォロワーは存在しない |
| **You are a Fan, not a Product** | あなたは商品ではなく顧客。データを売らない |
| **Authentic Over Curated** | 演出された充実より、ダメ全開のリアルの方が価値がある |

## プロダクト概要

| 項目 | 内容 |
|------|------|
| サービス名 | Sloth Feed（スロースフィード）|
| カテゴリ | キャラクターIP / SNS / ウェルビーイング周辺 |
| プラットフォーム | iOS / Android 想定。**PoC は Web アプリ** |
| 主な機能 | 投稿（ダメな行動のみ）・AI ナマケモノからの肯定コメント・サンドイッチUI・タイムライン |
| 収益モデル | **5レイヤー**：物販40% / ライセンス20% / コラボ15% / サブスク10% / 出版15%。**toBデータ販売 0%（完全禁止）** |

---

## 解決する課題

1. **だらけることへの罪悪感が消えない**
   仕事以外のことをする自分を、社会通念が「サボり」と定義し続けている

2. **「充実した人」との比較で自己評価が下がる**
   既存SNSは全員が「成果・充実した休日」を投稿する設計になっており、比較から逃げられない

3. **罪悪感が行動改善ではなく自己消耗で終わる**
   罪悪感を持つことで何かが解決するわけではなく、ただ疲弊するだけのループが続く

## 競合との差別化（4軸）

| 比較軸 | 既存ダメ系IP（コウペン等）/ 既存SNS | **Sloth Feed** |
|--------|--------------------|-----------|
| 投稿対象 | 「ちゃんとできた」を褒める | **「ダメだった」を誇らせる** |
| キャラの応答 | 静的な絵 + 固定セリフ | **動的（AI生成、ユーザー個別）** |
| 思想 | 可愛さ・共感のみ | **Larry Wall・ラッセル・老子の系譜** |
| プラットフォーム | 物販中心 / SNS連携は付随 | **SNSがIPの本体（生成・育成・体験装置）** |

詳細は [`docs/ideation/ideas.md`](../../docs/ideation/ideas.md) §4 参照。

## ファンとして遇する原則

Sloth Feed の事業倫理は以下の原則に基づく：

> **「あなたは商品ではなく、ファンです。」**

- ユーザーデータは売らない（マーケ部門・学術機関問わず）
- 加工レポートも売らない
- 広告掲載しない
- 収益はすべてキャラクターと思想の体験から得る
- これらは将来的に**会社定款レベルで禁止**する

詳細経緯は [Issue #5](https://github.com/is-tech-lab/Sloth-Lab/issues/5) を参照。
