# Project Overview — Sloth Feed

---

## ビジョン

> 「究極に堕落した人たちが、世界を平和にしている」

「仕事をしない」ことが弱さでも恥でもなく、ただの人間のあり方として当然に受け入れられる世界。
だらける・休む・何もしない——そのすべての時間が、社会を支える価値として認められている世界。
SNSとメディアが作り出した「成果を出し続けなければならない」という呪縛が解け、
仕事をしていないことで疲弊し鬱になっていく負のスパイラルが、この社会から消えている。

---

## キャッチコピー

> 「『仕事じゃないけど、、、』が世の中を変える」

「仕事じゃないけど、彼女のために洗い物しといた」
「仕事じゃないけど、昼休みに親にLINEした」
「仕事じゃないけど、帰りに牛乳を買い忘れなかった」

人々は毎日、仕事以外の行動を「仕事じゃないけど」と言い訳しながら流してきた。
Sloth Feed は、その言い訳ごと肯定することで、**仕事以外の行動こそが社会の土台だ**という新しい価値観をつくる。

---

## コンセプト

**「仕事じゃない行動」だけが投稿できる唯一のSNS。**

仕事の成果・旅行・充実した休日の投稿はAIフィルタリングで自動的に弾かれる。
タイムラインに積み上がるのは、全員の「仕事じゃないけど」だけ。
そこに競争はなく、比較もなく、あるのは「あなたのその行動が、誰かにとって意味があった」という事実だけ。

Instagram が「充実した自分」を演じる場所なら、
Sloth Feed は「仕事じゃない自分」をそのまま出せる場所。

## 人をダメにするメカニズム

ハッカソンのテーマ「人をダメにするサービス」において、このサービスが「ダメにする」仕組みを明示する。

**前提：このサービスが定義する「ダメ」**
今の社会では「仕事をしないこと＝ダメ」という固定観念がある。
引きこもり・鬱・だらけ——これらは弱者のラベルを貼られ、SNSやメディアで晒される。その比較と圧力が人を疲弊させ、鬱へと向かわせる負のスパイラルをつくっている。

Sloth Feed は「仕事をしない自分」を究極に肯定することで、このスパイラルの逆回転を起こす。

| 仕組み | 効果 |
|-------|------|
| 投稿のたびに仕事の成果をフィルタリングで弾く | 「仕事の成果はここには要らない」を繰り返し刷り込む |
| 怠惰な日常行動をAIが偉人の名言で称賛する | 「これでいいや」という感覚を定着させる |
| タイムラインが「仕事じゃない行動」だけで埋まる | 「みんなもだらけている」という集団規範を形成する |
| フォロワー数・いいね数を設計から消す | 「頑張る必要がない」という感覚を固定化する |

このフィードバックループが繰り返されることで、仕事への強迫観念が薄れ、ユーザーは究極の堕落へ向かう。その堕落は破壊ではなく、鬱スパイラルから解放された「ただ人間らしく生きている状態」だ。

**他のSNSの「ダメにする」との違い**

XやInstagramにも誹謗中傷・炎上・比較による自己嫌悪があり、人をダメにしている。
しかしそれは**消耗させる方向のダメ**だ。人を壊し、疲弊させ、孤立させる。
Sloth Feed のダメは逆方向——**解放的なダメ**だ。仕事への強迫観念を解体し、堕落を肯定し、平和にする。

## ターゲットユーザー

### ペルソナA：「罪悪感持ちのだらけ屋」（コアターゲット）

| 属性 | 内容 |
|------|------|
| 年齢・職業 | 24歳・社会人2年目（事務・営業など） |
| 年収 | 280〜350万円 |
| 生活 | 一人暮らし。仕事はこなせている。サボっているわけではない |
| 悩み | 帰宅後の「ちょっと休憩」が2〜3時間になり、「今日も何もできなかった」と寝る前に後悔する |
| SNS習慣 | Instagramで充実した人の投稿を見ては自己嫌悪するのが習慣になっている |
| 本音 | 「これでいい」と自分を許せるようになりたい。休んでいることに罪悪感を感じない日を過ごしたい |

**このペルソナへの提供価値**：「仕事じゃないけど」という言い訳ごと肯定されることで、就寝前の罪悪感ループを断ち切る。

| 属性 | 内容 |
|------|------|

## プロダクト概要

| 項目 | 内容 |
|------|------|
| サービス名 | Sloth Feed（スロースフィード） |
| カテゴリ | SNS / ライフスタイルアプリ |
| プラットフォーム | iOS / Android 想定のアプリだが、PocはWebアプリで作る|
| 主な機能 | 投稿（仕事以外の行動のみ）・AIコメント（偉人の名言・研究論文を引用した自動称賛）・フィルタリング（仕事成果・旅行・充実投稿を自動除外） |
| 収益モデル | ①freemium（月額480円プレミアム）②アンチハッスル・ブランドスポンサーシップ（思想一致ブランドのみ）|

---

## 解決する課題

1. **だらけることへの罪悪感が消えない**
   仕事以外のことをする自分を、社会通念が「サボり」と定義し続けている

2. **「充実した人」との比較で自己評価が下がる**
   既存SNSは全員が「仕事での成果・充実した休日」を投稿する設計になっており、比較から逃げられない

3. **罪悪感が行動改善ではなく自己消耗で終わる**
   罪悪感を持つことで何かが解決するわけではなく、ただ疲弊するだけのループが続く

---

## 競合との差別化

| 比較軸 | Instagram / X | Sloth Feed |
|--------|--------------|-----------|
| 投稿できる内容 | 制限なし（充実・成果が伸びる設計） | 仕事以外の行動のみ（フィルタリングで強制） |
| 評価軸 | いいね数・フォロワー数（競争） | AIコメントのみ・数字非表示（比較なし） |
| ユーザーが得るもの | 他者からの承認・自己顕示 | 「仕事以外の自分」への肯定感 |
| 社会へのメッセージ | 「もっと充実しろ・成果を出せ」 | 「仕事じゃない行動が、世の中を変える」 |
| 人をダメにする方向 | 比較・炎上・誹謗中傷による消耗（破壊的ダメ） | 仕事への強迫観念を解体する堕落の肯定（解放的ダメ） |
