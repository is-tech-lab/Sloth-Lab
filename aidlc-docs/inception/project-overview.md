# プロジェクト概要

このファイルはアイデア発想（Ideation）フェーズの出発点です。
以下4項目を記入してから `/ideation` を実行してください。

---

## プロダクトビジョン

自己研鑽が美徳とされる社会の中で、「ただ存在するだけで100点」という無条件の全肯定を届ける。
他者の怠惰と自分の怠惰が静かに共鳴し合う「ぬるま湯」の居場所をホーム画面に作ることで、不確実な時代を生き抜くための脳の余白——ネガティブ・ケイパビリティ——を、日本中の人々に育む。

---

## プロダクトコンセプト

**「共鳴する怠惰」——ホーム画面で生活するやる気ゼロのキャラが、近くにいる"同志の怠惰"を検知して増殖するウィジェットアプリ。**

アプリを開く必要すらない。「だるい」と感じた瞬間にキャラをタップするだけで、GPS連動により半径数km以内で今まさにだらけている人々を検知し、キャラが共鳴・増殖する。他人の怠惰が可視化されることで「サボっているのは自分だけではない」という安心感と、「自分より先にダメになっている人がいる」という密かな優越感が生まれ、ユーザーを心地よい依存状態へと誘う。

---

## コアバリュー

| 価値 | 説明 |
|------|------|
| **負の連帯感による安心** | 近くに"同志"がいることを可視化し、「一人でサボっている罪悪感」を消す |
| **密かな優越感** | 自分より先にダメになっている他者の存在を感知することで生まれる、罪悪感ゼロの自己肯定 |
| **無条件の全肯定** | 目標も評価も存在しない。生きているだけで100点という空間を提供する |
| **ゼロ摩擦の体験** | アプリを開かなくてよい。タップ一つ、ウィジェットだけで完結する極限の低摩擦設計 |
| **逆説的ウェルネス** | 堕落を肯定することで「宙ぶらりんの状態を受け入れる力」= ネガティブ・ケイパビリティを育成する |

---

## ターゲットユーザー

**メインターゲット：日本の20〜40代の働く人々**

- 仕事中や休日の午後に「だるいけど、自分だけがサボっているのでは？」という罪悪感を感じる人
- SNSの「充実した他者の姿」に疲れ、等身大の怠惰な人間と繋がりたい人
- 自己啓発・生産性向上アプリに食傷気味で、「ありのままでいい」と言ってくれる場所を求めている人
- スマホをなんとなく触ってしまう習慣があり、ウィジェットをよく使う人

**サブターゲット：**

- 「真面目に怠けたい」というパラドックスを楽しめるユーモアのある層
- メンタルヘルスに関心があり、無理をしない生き方を模索している人
