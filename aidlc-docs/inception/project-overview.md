# Project Overview — Refactor the World

## プロジェクトビジョン

**「世界はバグだらけだ。君が書き換えろ。」**

現実世界の非効率・不満・醜さを「バグ」と定義し、AIで即座に「理想の姿」へ変換。そのビジョンをSNSで共有し、企業が実装することで現実が変わる——「アーキテクトは動かない」が成立する世界を作る。

---

## コアコンセプト

### 3つの心理変質モデル

| 変質 | 変換前（現状） | 変換後（RTWがもたらす認知） |
|------|--------------|--------------------------|
| **怠惰の変質** | 「自分でやれば早い」という勤勉信仰 | 「自分が動くのはコストの無駄（＝美徳に反する）」 |
| **短期の変質** | 「待てば報われる」という忍耐信仰 | 「今すぐ視覚化できないものは無価値」 |
| **傲慢の変質** | 「他人のために何かする」という奉仕信仰 | 「他人の実行ユニットに、アイデアという養分を与えてやっている」 |

### UXフロー

```
Capture（捉える）
    ↓
  現実の「バグ」をスマホで撮影

AI Refactor（書き換える）
    ↓
  0.5秒で「あるべき姿」を生成
  バグレポート自動生成

Social Commit（公開する）
    ↓
  SNSで公開
  いいね / PR / スタンプ で評価

Real Deployment（実装を見届ける）
    ↓
  企業がデータ購入
  現実が変わっていくビルドログを監視
```

## ターゲットユーザー

### プライマリ：「アーキテクト気質の不満族」
- **年齢**：25〜35歳
- **属性**：都市生活者、IT系・クリエイター系職種
- **特徴**：「アイデアはあるが動かない」内的矛盾を抱える。SNSでの影響力を求める
- **動機**：承認欲求 × 優越感 × 即時達成感

### セカンダリ：「即席クリエイター」
- **年齢**：18〜24歳
- **属性**：学生、SNSネイティブ
- **特徴**：バズ目的で高品質コンテンツを量産したい

### 企業クライアント（B2B）
- 建設・都市計画・外食・小売・交通インフラ企業
- 「生のユーザー不満データ＋解決ビジョン」を市場調査として欲しがっている

---

## コアバリュー

1. **即時性**：思考が0.5秒で視覚化される体験。待つことを設計しない
2. **影響力**：椅子から動かずに現実を変える感覚。実装まで追跡可能
3. **優越感の正当化**：「批評家」「文句屋」ではなく「アーキテクト」として自己定義できる場
4. **フライホイール**：使うほどAIが賢くなり、企業データが充実し、影響力が増す自己強化ループ
