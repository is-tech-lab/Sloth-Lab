# 要件定義 — Sloth Feed PoC（IP事業 × 動的IP × AI技術）

> **本ドキュメントの前提（2026-05-09 更新）**
> Issue #5 の帰着により、Sloth Feed は IP事業として位置づけ直された。アプリは IP の入口・体験装置・コミュニティ装置として機能する。技術選定（Next.js / Claude API / DynamoDB / JWT）は維持しつつ、機能要件を**動的IP × AI技術**観点で再構築している。

---

## 意図分析サマリー

| 項目 | 内容 |
|------|------|
| **リクエストタイプ** | 新規プロジェクト（IP事業の入口アプリとしての PoC） |
| **スコープ** | システム全体（PoC：Web アプリ） |
| **複雑性** | 中程度〜やや高（AI動的応答 + RAG引用ライブラリ + 個別化記憶） |
| **フェーズ** | PoC Web アプリ（最終的にはモバイルアプリ + 物販 + ライセンス展開） |

## 機能要件

### FR-001: 「仕事じゃないけど」投稿機能

- ユーザーがテキストで「**仕事じゃないけど**」と前置きできるすべての行動を投稿できる：
  - **真の怠惰・無為・サボり**（布団から出ない・二度寝・録画一気見など）
  - **小さな善行**（家族にLINE・洗い物・植物の水やりなど）
  - **どちらも等しく受け入れる**（怠惰だけ／善行だけに偏らせない）
- 投稿前に AI フィルタリングを通過する
- フィルタリングに引っかかった場合（仕事の成果・キラキラ充実投稿）は「**ここは仕事じゃないあなたの場所です**」旨のメッセージを返す

**変更点（旧 → 新）**:
- 旧：「仕事じゃないけど」prefix を**強制**
- 新：prefix 強制を**撤回**。任意の文章で投稿可能。UI のサンドイッチ構造で「仕事じゃないけど〜世の中を変える」フレーミングを担保

### FR-002: AIフィルタリング

- Claude API を使用して投稿内容を判定する
- 以下のカテゴリは弾く：
  - 仕事の成果・昇進・業績報告
  - 旅行・観光・充実した休暇
  - スポーツ大会の結果・自己啓発の成果
  - キラキラした非ダメ系投稿全般
- 上記以外、特に**真の怠惰・無為・サボり投稿**は通過させる

### FR-003: AI ナマケモノ対話（コア機能）

**旧 FR-003「AIコメント機能」を、動的IP として再定義**：

- 投稿がフィルタリングを通過した直後、AI ナマケモノが**個別化された肯定コメント**を生成する
- コメントは「**5経路**」のいずれかに**必ず紐付けて**生成される（経路の詳細は `project-overview.md` 「ビジョンを支える5経路」参照）：

  | 経路 | 言語化のテンプレート（要旨） |
  |---|---|
  | ① 過剰生産社会へのブレーキ | 「あなたの[時間]は、社会の総労働時間から無駄な労働を削除した」 |
  | ② 創造の余白の保持 | 「あなたの[行動]中、DMNが活性化した。AIに代替されない人間性が守られた」 |
  | ③ 多様性の保護 | 「あなたの[行動]は、『頑張る一強』社会への選択肢を一つ守った」 |
  | ④ 自己への暴力の停止 | 「あなたが罪悪感を捨てた瞬間、社会のメンタルヘルス危機が一人分後退した」 |
  | ⑤ 集積による文化変容 | 「あなたの[行動]は、社会のテンポを下げる集合運動の1ピース」 |

- コメントには以下を必ず含める：
  - **5経路のうち1つの具体メカニズム**
  - **数字・科学・歴史**による裏付け
  - **偉人引用**（Larry Wall・ラッセル・老子・ニュートン・フレミング・ケインズ等）
  - **出典の明記**（ハルシネーション対策）
- 「それは偉業だ」「あなたはすごい」のような**抽象的な称賛**は許容しない（**何が、どう、世の中を変えるのか**を必ず言語化する）
- コメントは投稿とセットで DB に保存し、タイムラインに表示する
- スタンプ・いいね・リアクション機能は**一切設けない**（旧 Post モデルの `stamps` フィールドは削除）

**有料/無料の整合**：
- AI ナマケモノコメントは**基本機能として無料**で提供される（旧 commercialization で「プレミアム」と記述されていたが訂正）
- プレミアム（任意の年会費 ¥3,000）は**運動への賛同**であり、機能差別化ではない

### FR-004: タイムライン

- 全ユーザーのフィルタリング済み投稿を時系列（新しい順）で一覧表示する
- フォロワー・フォロー関係なく全投稿が表示される
- フォロワー数・いいね数・ランキングは**一切表示しない**

### FR-005: 自分の「仕事じゃないけど」投稿一覧

- 自分のこれまでの投稿（怠惰系・善行系問わず）と AI コメントを一覧で振り返ることができる
- スタンプ数等は**表示しない**（存在しないため）

### FR-006（新規）: AI ナマケモノの個別化記憶

- ユーザーごとに過去の投稿履歴を AI が参照する
- 「先週、3時間スマホを見ていたあなたへ」のような**継続性のある対話**を可能にする
- ユーザーごとに**ナマケモノとの関係性が育つ**設計

### FR-007（新規）: RAG 引用ライブラリ（5経路紐付け）

- AI ナマケモノが引用する偉人・哲学・科学・統計の出典を**RAG（検索拡張生成）**で管理する
- **各引用は5経路のいずれかにタグ付け**されており、AI が経路選択時に対応する引用を検索できる構造とする
- 引用ライブラリは以下を含む：

| 経路 | 主な引用源 |
|---|---|
| ① 過剰生産社会へのブレーキ | ラッセル『怠惰への讃歌』、ケインズ「孫の世代の経済的可能性」、過労死統計、労働時間国際比較 |
| ② 創造の余白の保持 | DMN脳科学研究、ニュートン（万有引力）、ケクレ（ベンゼン環）、ポアンカレ（数学発見）、フレミング（ペニシリン）、Larry Wall（三大美徳）|
| ③ 多様性の保護 | 老子『無為自然』、兼好法師『徒然草』、鴨長明『方丈記』、生物多様性研究 |
| ④ 自己への暴力の停止 | アドラー、ラッセル、現代メンタルヘルス研究、自殺率統計、燃え尽き症候群研究 |
| ⑤ 集積による文化変容 | Quiet Quitting動向、Lazy Girl Job、文化規範変容の社会学研究、SNS発の社会運動事例 |

- 出典の正確性を担保するため、**ハルシネーション対策**（出典を必ず明記）を実装
- 検索のロジック：
  1. 投稿内容から最も適合する経路（①〜⑤）を判定
  2. 該当経路の引用ライブラリから1〜2件を検索
  3. ナマケモノ人格 + 経路言語化テンプレ + 引用 を組み合わせて応答生成

### FR-008（新規）: サンドイッチUI構造

- 投稿カードは以下の構造で表示される：
  ```
  ┌─────────────────────────────────┐
  │ 仕事じゃないけど…                │ ← ブランドフレーム上部
  │─────────────────────────────────│
  │  [ユーザー投稿]                  │
  │─────────────────────────────────│
  │  🤖 [AI ナマケモノコメント]      │
  │─────────────────────────────────│
  │ …これが、世の中を変える。        │ ← ブランドフレーム下部
  └─────────────────────────────────┘
  ```
- ブランドフレーム上下が「仕事じゃないけど〜世の中を変える」を保証する
- これにより、投稿内容がどのような「ダメ」でも、ブランドの構文で包まれる

## PoC MVP から除外する機能

| 機能 | 理由 |
|------|------|
| SNSログイン（Google等） | 後フェーズで追加 |
| フォロー・フォロワー機能 | コアコンセプトに不要 |
| スタンプ・いいね機能 | 比較・承認欲求が生まれるため AI ナマケモノに代替 |
| プッシュ通知 | PoC不要（Year 2 で能動性ゼロ習慣化として追加検討）|
| 物販・コラボ機能 | PoC のスコープ外（Year 2 以降の事業拡張） |
| マルチモーダル拡張（画像・音声・AR） | Year 2 以降検討 |
| toBデータ販売・データ提供 | **永久に実装しない**（Issue #5 で確定） |

## 非機能要件

### NFR-001: パフォーマンス

- AI フィルタリング（Claude API）のレスポンスタイム: 5秒以内（PoC許容値）
- AI ナマケモノコメント生成のレスポンスタイム: 5秒以内（PoC許容値）
- タイムライン表示: 初回ロード3秒以内（PoC許容値）

### NFR-002: セキュリティ

- **PoC ではスキップ**（プロトタイプのため）
- 実装フェーズで JWT 認証の最小限の保護のみ実施

### NFR-003: テスト

- プロパティベーステスト: PoC ではスキップ
- 基本的な動作確認レベルのテストを実施

### NFR-004: デプロイ

- AWS上にデプロイ（Amplify または EC2 + DynamoDB）
- ローカル開発環境での動作確認が可能

### NFR-005（新規）: AI 出力の倫理性

- ハルシネーション対策：偉人引用は RAG ライブラリから検索した実在の引用のみ使用
- 出典明記：AI コメントには必ず引用元を明記する
- 「ダメ礼賛が依存を生む」リスク対策：AI が一定時間の継続使用を検知した際は「**そろそろ寝ましょう**」のような切り上げ提案を返す

### NFR-006（新規）: ユーザーをファンとして遇する

- ユーザーデータは外部に**販売しない**
- 広告は**掲載しない**
- 加工データレポートも**販売しない**
- これらは将来的に**会社定款レベルで禁止**する

## データモデル（概要）

### User（ユーザー）

| フィールド | 型 | 説明 |
|-----------|-----|------|
| userId | String (PK) | UUID v4 |
| email | String | メールアドレス（GSI: email-index）|
| passwordHash | String | bcrypt ハッシュ |
| createdAt | String (ISO) | 登録日時 |

### Post（仕事じゃないけど投稿）

| フィールド | 型 | 説明 |
|-----------|-----|------|
| postId | String (PK) | UUID v4 |
| content | String | 投稿本文（仕事じゃない行動のテキスト：怠惰系・善行系問わず） |
| authorId | String | 投稿者の userId（GSI: authorId-createdAt-index）|
| aiComment | String | AI ナマケモノが生成した肯定コメント |
| aiCitationSource | String | 引用元（例：「Larry Wall」「ラッセル『怠惰への讃歌』」）|
| createdAt | String (ISO) | 投稿日時 |

**変更点**：
- 旧 `stamps` フィールドを**削除**（スタンプ機能は存在しないため）
- `aiCitationSource` を**追加**（出典明記のため）

### FilterResult（フィルタリング結果）

| フィールド | 型 | 説明 |
|-----------|-----|------|
| allowed | Boolean | 通過/除外 |
| reason | String | 除外理由（除外時のみ）|

## ユーザーシナリオ（主要）

### シナリオ1A: 怠惰系の投稿をする

1. ユーザーがテキストを入力（例：「布団から3時間出られなかった」）
2. Claude API がフィルタリング判定（仕事系投稿でないことを確認）
3. 通過 → AI ナマケモノが**経路①過剰生産抵抗**等を選び、ケインズ等の引用付きで応答
4. サンドイッチUI で表示

### シナリオ1B: 善行系の投稿をする

1. ユーザーがテキストを入力（例：「彼に洗い物しといた」）
2. Claude API がフィルタリング判定（仕事系投稿でないことを確認）
3. 通過 → AI ナマケモノが**経路③多様性保護**等を選び、「KPI評価されない領域での貢献」として応答
4. サンドイッチUI で表示

### シナリオ2: タイムラインを見る

1. ユーザーがトップページを開く
2. 全ユーザーの**怠惰系・善行系混合**の「仕事じゃないけど」投稿が時系列で表示される（サンドイッチUI）
3. 数字（いいね・フォロワー）は一切表示されず、共同体感を得る

### シナリオ3: 自分の「仕事じゃないけど」を振り返る

1. ユーザーが「自分の投稿」ページを開く
2. 自分の過去の投稿（怠惰系・善行系混合）と AI ナマケモノからの肯定コメントが一覧で表示される
3. 「**こんなに仕事じゃないことをやってきたんだ**」という自己肯定感を得る

## 成功基準（PoC）

- [ ] ダメ投稿 → フィルタリング → AI ナマケモノ肯定 → タイムライン表示の一連のフローが動作する
- [ ] 「仕事の成果」「旅行」投稿が Claude API に正しく除外される
- [ ] 「布団から3時間出られなかった」のような**真のダメ投稿**が正しく通過する
- [ ] AI ナマケモノコメントが偉人引用付きで生成される（RAG ライブラリ動作確認）
- [ ] サンドイッチUI で「仕事じゃないけど…世の中を変える」が常に表示される
- [ ] スタンプ機能が**存在しないこと**を確認（旧 stamps フィールド削除確認）
- [ ] AWS DynamoDB への読み書きが機能する
- [ ] AI ハルシネーション対策（出典明記）が動作する
